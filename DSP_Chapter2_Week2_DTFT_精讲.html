Chapter 2 从“离散时间信号从哪来”开始：对模拟信号做等间隔采样，相邻样本相隔 T 秒。

x[n] = xa(nT),    −∞ < n < ∞
三个符号

T：采样间隔（秒）；1/T：采样频率 fs（Hz）；n：整数样本序号。时间轴被离散化，幅度没有被量化 —— 所以 x[n] 仍是 Week 1 说的“第 2 类信号”。

课件的语音例子

T = 125 μs ⟹ fs = 8 kHz。取 32 ms 长的一段，对应 32 ms / 125 μs = 256 个样本 —— 正好是图 2.2 里标注的 “256 samples”。

为什么先讲采样

因为“离散”这个前提一旦成立，第 4、5 节的频率周期性就不可避免（连续时间没有这回事）。采样定理与混叠是 Chapter 4 的内容，这里只建立 x[n] = xa(nT) 这个映射。

02基本序列与序列运算slide 4–5 · §2.1.1

序列之间的运算是逐点（sample-by-sample）进行的；其中“延迟”和“用冲激表示任意序列”是后面卷积的两块基石。

三种基本运算

① 逐点乘 / 逐点加　y[n] = x1[n] · x2[n],   y[n] = x1[n] + x2[n] ② 乘标量　y[n] = c · x[n]（每个样本都乘同一个数） ③ 延迟（平移）　y[n] = x[n − n0]  n0 > 0 右移 = 延迟；n0 < 0 左移 = 超前

单位冲激（unit sample）

δ[n] = 0,  n ≠ 01,  n = 0

任意序列 = 加权、平移的冲激之和slide 5

课件给的例子是四个非零样本的情形：

p[n] = a−3δ[n+3] + a1δ[n−1] + a2δ[n−2] + a7δ[n−7]

推广到一般形式（这个式子要背）：

x[n] = ∞∑k = −∞x[k] δ[n − k]
为什么这个分解重要：它是第 11 节卷积的唯一入口 —— 先分解成冲激（这一步只用信号本身的性质），再利用系统的线性和时不变性把每个冲激的响应加起来（这一步才用到系统）。“分解 + 叠加”就是整个 LTI 理论。

03单位阶跃与冲激的互推关系slide 6

这两个基本序列互为“差分／累加”，是 Week 1 里“累积系统 ↔ 差分系统”关系的序列版本。

u[n] = 1,  n ≥ 00,  n < 0
① 用冲激累加出阶跃　u[n] = n∑k = −∞δ[k] ② 用阶跃差分出冲激　δ[n] = u[n] − u[n−1] ③ 另一种写法（向后累加）　u[n] = ∞∑k = 0δ[n − k]
三个式子说的是同一件事：u[n] 是 δ[n] 的累积和，δ[n] 是 u[n] 的一阶后向差分。① 与 ③ 只差一个变量替换 k → n−k，一个从左往右数、一个从右往左数，因为阶跃在 n ≥ 0 上恒为 1，两种数法得到同一个序列。

04指数序列与正弦序列slide 7–8

指数序列 x[n] = Aαn 在 LTI 系统分析里地位特殊：它是所有 LTI 系统的特征函数（Chapter 2 后半段与 Chapter 3 的 z 变换都建立在这上面）。

实指数　x[n] = A αn，A, α 为实数 正弦　x[n] = A cos(ω0n + φ)，对一切 n

当 α 与 A 都是复数时slide 8

令 α = ejω0、A = |A|ejφ，则

x[n] = A αn = |A|ejφ·ejω0n = |A| cos(ω0n + φ) + j|A| sin(ω0n + φ)

即：一个复指数序列的实部与虚部，分别是两个相位差 90° 的实正弦。当 |α| = 1（只有模为 1 时）课件把 x[n] = A ejω0n 称为复指数序列（complex exponential sequence）。

第一条重要区别：频率是周期的slide 8

ej(ω0 + 2π)n = ejω0n·ej2πn = ejω0n

因为 n 是整数，ej2πn = 1 恒成立。所以离散时间复指数的频率以 2π 为周期 —— 连续时间指数没有这个性质（ej(Ω+2π)t ≠ ejΩt，除非 t 是整数）。

与 Week 1 的对应：Week 1 用的说法是 cos[(ω0+2π)n+φ] = cos(ω0n+φ)；这里换成了复指数写法，结论完全一致。离散域的“频率”本质上是一个圆上的角，转满一圈（2π）就回到原点。

05频率的周期性、ω0 的取值区间与信号的周期性slide 9–10

由频率的 2π 周期性直接得到两条实用结论：讨论离散频率只需看一个长度 2π 的区间；而“信号是否周期”则另有一番条件。

唯一频率区间：0 ≤ ω0 < 2π  （等价地 −π < ω0 ≤ π）

任何 ω0 都可以通过加／减 2π 的整数倍搬进这个区间，而序列一个样本都不变。

第二条重要区别：连续时间总是周期，离散时间不一定slide 9

要求 A cos(ω0n + φ) 以 N 为周期，即

A cos(ω0(n + N) + φ) = A cos(ω0n + φ)  ⟹  ω0N = 2πk N, k 均为整数，N > 0；取最小的 N 即基波周期 N0

这与 Week 1 第 3 节的条件完全相同——只是这里用 ejω0n 的相位条件重新推了一遍。判定要点仍是：ω0/2π 为有理数 ⟺ 周期。

图 5 的读法：(a) 与 (d) 之间只差“最快”与“不动”；(b) π/8 与 15π/8 = 2π − π/8 是同一条序列；(c) π/4 与 7π/4 同理。离散时间的最高振荡频率是 ω0 = π（第 (d) 图，序列在 +1, −1 之间每拍翻转），超过它就折回来 —— 这就是 Chapter 4 混叠的伏笔。

06离散时间系统与无记忆系统slide 11–13 · §2.2, §2.2.1

系统就是一个把输入序列映射成输出序列的变换。课件用滑动平均作为贯穿全章的样板系统，因为它同时是线性、时不变、因果（当 M1=0）、稳定、有记忆的。

y[n] = T{x[n]}

样板系统：滑动平均（moving average）slide 11

y[n] = 1M1 + M2 + 1M2∑k = −M1x[n − k]

它把 n 附近共 M1+M2+1 个样本求平均：M1 个“过去”的、1 个“现在”的、M2 个“未来”的。窗口会伸进未来，所以因果与否取决于 M1 是否为 0（第 9 节）。

无记忆系统§2.2.1

输出 y[n] 在任意 n 上只依赖同一时刻的输入 x[n]：

课件例子：y[n] = (x[n])2
对比：平方系统无记忆；滑动平均与累积器都有记忆（要用到邻点或全部历史）。这条判断和 Week 1 第 9 节完全一致。

07线性系统slide 14–15 · §2.2.2

线性由两条性质组成，缺一不可。合起来就是叠加原理，它才是把“冲激响应”推广成“卷积”的那把钥匙。

I. 可加性（additive）　T{x1[n] + x2[n]} = T{x1[n]} + T{x2[n]} = y1[n] + y2[n] II. 齐次性（homogeneity / scaling）　T{a x[n]} = a T{x[n]} = a y[n]

叠加原理与推广

叠加：T{a x1[n] + b x2[n]} = a T{x1[n]} + b T{x2[n]} 推广（任意多项）：若 x[n] = ∑kakxk[n]，则 y[n] = ∑kakyk[n]

例：累积器是线性的slide 15

设 y1[n] = n∑k=−∞x1[k]、y2[n] = n∑k=−∞x2[k]，输入取 x3[n] = a x1[n] + b x2[n]：

y3[n] = n∑k=−∞(a x1[k] + b x2[k]) = a n∑k=−∞x1[k] + b n∑k=−∞x2[k] = a y1[n] + b y2[n]  ✓
结论：累积器线性（但它不稳定、有记忆 —— 性质和性质之间互不蕴含）。
易错点：只验齐次性就下结论。反例：y[n] = x[n]x[n−1] 满足齐次（(ax)(ax) = a2x·x ≠ a x·x —— 其实连齐次都不满足）。稳妥做法是把两条都写出来，或者找一个不满足叠加的具体输入反例。

08时不变系统（shift invariant）slide 16 · §2.2.3

系统本身不随时间漂移：输入平移多少，输出就平移多少，波形一点不变。

x[n] → y[n]  ⟹  x[n − n0] → y[n − n0]

例：累积器是时不变的slide 16

第 1 步　定义平移后的输入 x1[n] = x[n − n0]，求它进系统后的输出：

y1[n] = n∑k=−∞x1[k] = n∑k=−∞x[k − n0]

第 2 步　换元 k′ = k − n0，于是 k = k′ + n0，求和上限变为 k′ = n − n0：

y1[n] = n − n0∑k′ = −∞x[k′]

第 3 步　认出这就是原输出的平移：

y1[n] = y[n − n0]  ✓
结论：累积器时不变。关键手法是换元后上限也跟着平移（n → n − n0）——漏掉这一步就会错判成“时变”。
判断时变的最快反例模板：凡是输入或输出里出现 n 的“非平移型”缩放／相乘（如 x[Mn]、n·x[n]、x[−n]、x[n]·n），基本都是时变。Week 1 的压缩系统 y[n]=x[Mn] 就是同一类反例。

09因果系统slide 17 · §2.2.4

因果 = 输出不预知未来。严格表述：对每一个 n0，y[n0] 只依赖 n ≤ n0 的 x[n]。

系统时域关系因果？理由
前向差分
Forward difference		 y[n] = x[n+1] − x[n] 非因果 要用到下一拍的 x[n+1]
后向差分
Backward difference		 y[n] = x[n] − x[n−1] 因果 只用到现在与上一拍

10BIBO 稳定性slide 18 · §2.2.5

有界输入必有有界输出。课件用一个漂亮的反例说明累积器不稳定。

|x[n]| ≤ Bx < ∞  for all n ⟹  |y[n]| ≤ By < ∞  for all n

反例：累积器slide 18

取有界输入 x[n] = u[n]（Bx = 1），输入完全有界。累积器输出：

y[n] = n∑k=−∞u[k] = 0,   n < 0n + 1, n ≥ 0 n → ∞ ⟹ y[n] = n + 1 → ∞
结论：不存在有限的 By 使 |y[n]| ≤ By 对所有 n 成立（n+1 > By 迟早发生）⟹ 累积器不稳定。
和 Week 1 串起来：累积器的 h[n] = u[n]，而 ∞∑n=0|u[n]| = ∞ ⟹ 绝对不可和 ⟹ 不稳定。第 12 节会把这条“定义法”升级成“看 h[n] 的判据”。

11LTI 系统与卷积slide 19 · §2.3

本节是全章的高潮：线性 + 时不变 ⟹ 一个系统的全部行为，都压缩在一个序列 h[n] 里。课件把这一步拆成三个明确的推理阶段。

第 0 步：定义冲激响应

令输入为 δ[n]，输出记为 h[n]（impulse response）：

h[n] = T{δ[n]}

并且对延迟 k 拍的冲激，记其响应为

hk[n] = T{δ[n − k]}

三步推理

步骤用到的性质得到的结果
① 信号自身的分解（第 2 节） x[n] = ∞∑k=−∞x[k] δ[n − k]
② 线性（第 7 节）：求和与 T{·} 可交换 y[n] = T{x[n]} = ∞∑k=−∞x[k] T{δ[n − k]}
③ 时不变（第 8 节）：T{δ[n−k]} = h[n−k] y[n] = ∞∑k=−∞x[k] h[n − k] = x[n] ∗ h[n]
卷积和（convolution sum） y[n] = ∞∑k=−∞x[k] h[n−k]  =  x[n] ∗ h[n]
系统x[n]→h[n]→y[n] = x[n] ∗ h[n]
一句话总结这章的逻辑链：“任意信号 = 冲激的加权和”（纯信号性质）→ “系统线性 ⟹ 响应 = 响应的加权和”（只需线性）→ “系统时不变 ⟹ 每个响应都是 h[n] 的平移”（才用到时不变）→ 卷积。所以：卷积 = 线性 + 时不变 的必然结果，两者缺一不可。
易错点：卷积和里的 h[n−k] 是翻转再平移，不是 h[k]。手算时把 h[·] 翻转、再平移 n、再与 x[·] 逐点相乘求和 —— 这正是 Lab Week 1（图形卷积）要画的“翻转—平移—相乘—求和”四步。

12LTI 系统的级联、并联与两条判据slide 20–21 · §2.4

有了卷积，系统的连接方式可以用代数运算描述；稳定性和因果性也可以只看着 h[n] 下结论。

级联（cascade）

(a)x[n]→h1[n]→h2[n]→y[n]
(b)x[n]→h2[n]→h1[n]→y[n]
(c) 等效x[n]→h1[n] ∗ h2[n]→y[n]
x[n] ∗ h1[n] ∗ h2[n] = x[n] ∗ (h1[n] ∗ h2[n])

并联（parallel）

(a)x[n]→h1[n]→+→y[n]
　x[n]→h2[n]↗+→y[n]
(b) 等效x[n]→h1[n] + h2[n]→y[n]
x[n] ∗ h1[n] + x[n] ∗ h2[n] = x[n] ∗ (h1[n] + h2[n])

两条判据（只依赖 h[n]）

稳定性

LTI 系统 BIBO 稳定 ⟺ h[n] 绝对可和：

S = ∞∑k=−∞|h[k]| < ∞
因果性

LTI 系统因果 ⟺ 冲激响应在负时间上恒为零：

h[n] = 0  for  n < 0
两条判据的来历：稳定性来自 |y[n]| = |∑kh[k]x[n−k]| ≤ Bx∑k|h[k]|，右边要有限就必须 Σ|h[k]| < ∞；因果性来自卷积里 h[k] 乘的是 x[n−k]，k < 0 就意味着取未来输入。

13线性常系数差分方程（LCCDE）与框图实现slide 22–26 · §2.5

微分方程的离散对应物。它既能描述系统（输入输出关系的紧凑形式），又能实现系统（直接画出计算框图，对应 Chapter 5–7 的滤波器结构）。

一般形式 N∑k = 0ak y[n−k]  =  M∑m = 0bm x[n−m]

例 1　累积器的差分方程与框图slide 22–23 · Figure 2.15

y[n] = n∑k=−∞x[k] = x[n] + n−1∑k=−∞x[k] = x[n] + y[n−1] ⟹  y[n] − y[n−1] = x[n] N = 1,  a0 = 1,  a1 = −1,  M = 0,  b0 = 1

差分方程让“怎么算”变得具体：每次只需一次加法和一次存取（保存上一拍的 y[n−1]）。这是 IIR（无限冲激响应）结构的最简形式。

例 2　滑动平均的差分方程与框图slide 24–26 · Figure 2.16

取 M1 = 0（因果），MA 系统为

y[n] = 1M2 + 1M2∑k = 0x[n − k]

它的冲激响应可以用阶跃表示（也可以看成“矩形窗 × 累积”）：

h[n] = 1M2 + 1(u[n] − u[n − M2 − 1]) = 1M2 + 1(δ[n] − δ[n − M2 − 1]) ∗ u[n]

把 MA 改写成递推形式（课件 Figure 2.16 的结构）：先对输入做“当前值减 M2+1 拍前的值”并乘以衰减系数，得到中间信号

x1[n] = 1M2 + 1(x[n] − x[n − M2 − 1])

再让 x1[n] 过一个累积器（即 y[n] = y[n−1] + x1[n]），把两式合并：

y[n] − y[n−1] = 1M2 + 1(x[n] − x[n − M2 − 1])
Figure 2.16x[n]→衰减器 1/(M2+1)→累加器→y[n]
　→(M2+1) 拍延迟↑相减后送入
关键结论（slide 26 原话的意思）：同一个 LTI 系统可以有无穷多个不同的差分方程来描述。上面 MA 的“直接形式”（累加 M2+1 项）和“递推形式”（一对差分 + 累积器）给出完全相同的 h[n]，但计算量大不相同：直接形式每拍要 M2+1 次乘加，递推形式只要常数次。这正是 Chapter 6/7 讨论“实现结构”的动机。
易错点：递推形式里 y[n] 依赖自己，属于 IIR 结构；但它的冲激响应仍然是有限的（M2+1 项），因为分子的差分把累积器的拖尾精确抵消掉了。所以：“有反馈” ≠ “IIR 冲激响应”，要看分子分母是否真的把拖尾消掉。

14DTFT 的定义与收敛条件slide 27–28 · §2.7

从这一节开始进入频域。DTFT 把非周期序列映射成 ω 的连续、以 2π 为周期的函数 —— 注意这个“连续”，它是离散时间 ↔ 周期频谱的对偶关系的另一半。

分析式（DTFT） X(ejω) = ∞∑n = −∞x[n] e−jωn
综合式（inverse DTFT） x[n] = 12π　∫2πX(ejω) ejωn dω  =  12ππ∫−πX(ejω) ejωn dω

综合式的积分区间是任意长度为 2π 的区间（通常取 [−π, π]），因为 X(ejω) 以 2π 为周期。

什么时候 DTFT 存在？

要求级数对每个 ω 都收敛到有限值：

|X(ejω)| < ∞   for all ω

由三角不等式得到充分条件：

|X(ejω)| = |∞∑n=−∞x[n]e−jωn| ≤ ∞∑n=−∞|x[n]|·|e−jωn| = ∞∑n=−∞|x[n]| < ∞
结论：序列绝对可和 ⟹ DTFT 存在，而且级数一致收敛到 ω 的连续函数。

S1 = 1(1 − (1/2)e−jω)2

第 3 步　左支（n < 0）　令 m = −n（m ≥ 1），则 n = −m、|n| = m、n+1 = 1−m，并记 a = (1/2)ejω：

S2 = ∞∑m = 1(1 − m)(12)mejωm = ∞∑m = 1(1 − m)am = ∞∑m = 1am − ∞∑m = 1m am = a1 − a − a(1 − a)2 = a(1 − a) − a(1 − a)2 = −a2(1 − a)2

代回 a = (1/2)ejω，即 a2 = (1/4)ej2ω：

S2 = −(1/4)ej2ω(1 − (1/2)ejω)2

第 4 步　合并

答案：X2(ejω) = 1(1 − (1/2)e−jω)2 − (1/4)ej2ω(1 − (1/2)ejω)2
教学点① 双边序列必须左右分开求和，且两支的比值不同：右支用 r = (1/2)e−jω，左支换元后用 a = (1/2)ejω（指数上 e−jωn 变成 e+jωm）。② 因为 x2 是实、偶序列，X2 必须是实、偶函数 —— 可以看出上式在 ω → −ω 下确实不变（第一项与第二项互换），可用来检算。③ 在 ω = 0 处检算：X2(ej0) = 4 − 1 = 3，而直接求和 Σx2[n] = 4 + (−1) = 3 ✓
Q3

求 x[n] = u[n] − u[n−4] 的 DTFT

Finite-length rectangular pulse

第 1 步　先写清支撑集：x[n] = 1 for n = 0,1,2,3，其余为 0。所以求和只有 4 项：

X(ejω) = 3∑n = 0e−jωn = 1 + e−jω + e−j2ω + e−j3ω

第 2 步　用有限几何和公式（M = 3）：

X(ejω) = 1 − e−j4ω1 − e−jω
答案：X(ejω) = 1 + e−jω + e−j2ω + e−j3ω = 1 − e−j4ω1 − e−jω
更进一步（课件 Table 2.3 第 9 对的用法）把分子分母都提出相位因子，可以写成幅度 × 线性相位的形式：
X(ejω) = e−j2ω(ej2ω − e−j2ω)e−jω/2(ejω/2 − e−jω/2) = e−j3ω/2 sin(2ω)sin(ω/2)
这解释了两件事：① 线性相位 −3ω/2 对应“群延迟 = 3/2 拍”（4 点窗的中心在 n = 1.5）；② 幅度是 Dirichlet 核 sin(2ω)/sin(ω/2)，在 ω=0 处极限为 4（= 窗长），并带有一串旁瓣。这正是矩形窗频谱的典型形状，也是 Chapter 7 里“矩形窗旁瓣高（−13 dB）、不适合做滤波器”的根源。
检算：X(ej0) = 1+1+1+1 = 4 = 序列长度；X(ejπ) = 1 −1 +1 −1 = 0 = 直流以外的偶次零点。任何 N 点矩形脉冲都满足这两条，可以快速自查。
Q4

求 x[n] = (1/4)nu[n] + δ[n−2] 的 DTFT

Linearity + table lookup

第 1 步　两项之和，用线性定理（Table 2.2 第 1 条）分别求再相加：

X(ejω) = DTFT{(1/4)nu[n]} + DTFT{δ[n−2]}

第 2 步　查表：第 4 对（a = 1/4，满足 |a|<1）与第 2 对（n0 = 2）：

(1/4)nu[n] ⟷ 11 − (1/4)e−jω δ[n−2] ⟷ e−j2ω
答案：X(ejω) = 11 − (1/4)e−jω + e−j2ω
