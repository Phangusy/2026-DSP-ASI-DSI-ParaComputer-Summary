01信号与信号的四种分类slide 1–5

课件从最基础的定义切入：信号是承载信息的函数，信息是信号传给接收者的有意义的数据。一个信号可以是单个独立变量的函数，也可以是多个独立变量的函数——本课程的自变量是时间（t 或 n），图像处理里图像就是含两个空间变量 (x, y) 的二维信号。

时间轴：连续 / 离散

连续时间 x(t)，自变量取连续值；离散时间 x[n]，自变量只取整数。离散时间信号在非整数点没有定义——例如 x[1.7] 无意义，不是 0。

幅度轴：连续 / 离散

幅度可以取连续区间内的任意值，也可以被量化（quantised）成有限个离散电平。量化只发生在幅度方向，与时间是否离散无关。

信号处理

“把信号变换成适合某一应用的形式”的运算统称信号处理：滤波（filtering）、调制（modulation）、放大（amplification）都是例子。

两个坐标轴各取“连续/离散”，共四种组合：

#类型时间轴幅度轴说明
1模拟信号 Analog连续连续传统的 x(t)，示波器上看到的波形
2离散时间信号 Discrete-time离散连续x[n]，幅度仍是精确的实数 —— 本课程的主体
3数字信号 Digital离散离散时间离散 + 幅度量化，DSP 芯片实际处理的形式
4时间连续 + 幅度离散连续离散阶梯状波形（采样保持 + 量化），如 DAC 输出
课件原话：“In this subject, we deal with the second type of signal, which leads to type 3 signals later.” —— 本课程只处理第 2 类（离散时间、连续幅度），后面（Chapter 4 采样）再引出第 3 类。

课件用一个具体例子定义了什么叫“信号”：

x[−2] = 1.6,   x[0] = 1.8,   x[3] = −1.5
x[n] = 0   for  n < −2  or  n > 3;    x[1.7]  is undefined

02四个基本序列slide 6–7

这四个序列构成了离散时间信号分析的全部“字母表”：任意序列都能用冲激表示（第 10 节），任意 LTI 系统的响应都能由对这四个信号的理解推出。

#序列定义要点
1 单位冲激/单位采样
Unit sample		 δ[n] = 1,  n = 00,  n ≠ 0 只在原点取 1；与 u[n] 的关系见下
2 单位阶跃
Unit step		 u[n] = 1,  n ≥ 00,  n < 0 “开关”信号，用来截断序列
3 实指数
Real exponential		 x[n] = an，a 为实数 |a| < 1 单调衰减，|a| > 1 单调增长，a < 0 变号振荡
4 正弦
Sinusoidal		 x[n] = A cos(ω0n + φ) 不一定周期——这是与连续时间最大的差别（第 3 节）

冲激与阶跃互为“差分 / 累加”slide 7 式 1–2

δ[n] = u[n] − u[n − 1] u[n] = ∞∑k = 0δ[n − k]

这两个式子是把“差分”和“累加”互为逆运算这件事，放在最基础的两个序列上演示；第 14 节的差分方程就是它的推广。

正弦的周期性条件slide 7 式 4

对离散正弦 x[n] = A cos(ω0n + φ)，周期条件是存在整数 k 与最小正整数 N0 使

ω0N0 = 2πk  ⟺   ω0 = 2πkN0

03离散正弦信号的周期性slide 8–9, 14

这是 Chapter 1 的第一个“坑”，也是 Tutorial Q1 的全部内容。连续时间余弦永远周期；离散时间余弦不一定周期。

连续性对比

A cos(ω0t + φ) 对任意 ω0 都周期；A cos(ω0n + φ) 只有当 ω0N = 2πk 有整数解时才周期。

可操作的判据

把条件整理成 ω02π = kN：ω0/2π 是有理数 ⟺ 周期。有理数约分后分母就是基波周期 N0。

为什么要 k

N 必须是整数，而 N = 2πk/ω0 一般不是整数；必须挑合适的 k 让 N 落成整数。

例 1　ω0 = 1，是否周期？slide 9

1 = 2πkN  ⟹   N = 2πk

对任何非零整数 k，N 都不是整数 ⟹ 非周期。

例 2　ω0 = 2π/7，是否周期？slide 9

2π7 = 2πkN  ⟹   N = 7k N = 7, 14, 21, …  ⟹   N0 = 7

例 3　求 x[n] = cos(πn/4) 的基波周期slide 14

ωN = 2πk  ⟹   π4N = 2πk  ⟹   N = 8k k = 1 ⟹ N0 = 8

代回验证（这一步考试里写上去能拿分）：

x[n + 8] = cos[π(n + 8)4] = cos(πn4 + 2π) = cos(πn4) = x[n]
速算口诀：ω0 = 2πk/N 里把 2π 约掉，剩下 N = 2k·(2π 的系数分母 / ω0 的系数)。对 ω0 = πn/4 型（ω0 = mπ/p），基波周期就是 2p/gcd(2p, m)：如 ω0 = π/4 → 2·4/gcd(8,1) = 8。含 √2、1、e 等无理数系数时，ω0/2π 无理由 → 非周期。

04频率等价性与混叠slide 10–13

第二个“坑”：离散时间信号的频率不是唯一的，相差 2π 的两个频率给出完全相同的序列。

差别的根源在于 n 是整数

cos[(ω0 + 2πr)n + φ] = cos(ω0n + φ + 2πrn) = cos(ω0n + φ)
因为 2πrn 是 2π 的整数倍，r 取任何整数都成立

例：令 ω0 → ω0 + 2π：

cos[(ω0 + 2π)n] = cos(ω0n + 2πn) = cos(ω0n)

而对连续时间 cos(ωt + φ)，增大 ω 只会把波形在时间上压缩、频率真的变高——两者行为不同。

唯一频率区间

离散时间 cos(ω0n + φ)

可任选唯一区间 −π < ω0 ≤ π 或 0 ≤ ω0 < 2π。所有频率都被“折叠”进这一条长度 2π 的区间里。

连续时间实余弦

取非负频率表示用 0 ≤ Ω0 < ∞；负频率可以吸收进相位里，信息不丢失，所以频率轴是无限长的。

振荡速率在一个周期内“折返”

当 ω0 从 0 增到 π，振荡越来越快；从 π 增到 2π，振荡又变慢，到 2π 时与 ω0 = 0 完全相同。下图 9 个面板把这件事实完整画了出来：

为什么重要：离散时间下最高的“有效”振荡频率是 ω0 = π（即归一化频率 f = 1/2，Nyquist）。超过 π 的频率不会变成更快的振荡，而是折回来伪装成低频——这正是 Chapter 4 采样定理与混叠（aliasing）的根源，也是 Lab Week 5 用 STM32F4 ADC 要看的现象。

05LTI 系统与线性slide 14–17

系统就是把输入序列映射成输出序列的算子 y[n] = T{x[n]}。LTI = Linear（线性）+ Time-Invariant（时不变），这两个性质合起来才使得“卷积”成为可能，也是整门课的主线。

线性的两个条件slide 15

可加性 Additivity

T{x1[n] + x2[n]} = T{x1[n]} + T{x2[n]}

齐次性 Homogeneity

T{a·x[n]} = a·T{x[n]}，a 为标量：输入乘 a，输出就乘 a。

两者合起来就是叠加原理（superposition）：

x1[n] → y1[n],   x2[n] → y2[n]  ⟹   a x1[n] + b x2[n] → a y1[n] + b y2[n]

例 1　累积系统是线性的slide 16

累积系统 y[n] = n∑k = −∞x[k]。取 x3[n] = a x1[n] + b x2[n]，则

y3[n] = n∑k = −∞[a x1[k] + b x2[k]] = a n∑k = −∞x1[k] + b n∑k = −∞x2[k] = a y1[n] + b y2[n]

求和是线性的，所以累积系统线性。（但它不是 BIBO 稳定的，也不是无记忆的——见第 8、9 节。）

例 2　y[n] = log10(|x[n]|) 是非线性的slide 17

只要找出一个反例就能否定线性。取

x1[n] = 1 → y1[n] = log101 = 0 x2[n] = 10 → y2[n] = log1010 = 1 x3[n] = x1 + x2 = 11 → y3[n] = log1011 log1011 ≈ 1.041 ≠ log101 + log1010 = 1
结论：对数系统非线性。判线性最省力的方法是先试叠加再找反例，不要试图对所有输入证明。

06时不变性slide 18–19

时不变（time-invariant）说的是：系统本身不随时间变化，输入平移多少，输出就平移多少，形状一点不改。

时移性质：x1[n] = x[n − n0]  ⟹   y1[n] = y[n − n0]

例　压缩系统 y[n] = x[Mn] 是时变的slide 18–19

其中 M 是正整数，−∞ < n < +∞。检验时移性质时，注意先把输入整体平移再进系统：

x1[n] = x[n − n0]  ⟹   y1[n] = x1[Mn] = x[Mn − n0] 而  y[n − n0] = x[M(n − n0)] = x[Mn − Mn0] x[Mn − n0] ≠ x[Mn − Mn0]  (n0 ≠ 0, M > 1)
结论：M > 1 时压缩系统时变（每压缩一次就相当于把时移量也“压缩”了 M 倍，两者对不上）。M = 1 时系统是恒等系统 y[n] = x[n]，时不变。
易错点：这一步最常见的错是算成 y1[n] = x[M(n − n0)]。正确做法是 y1[n] = T{x[n − n0]}，即把 x[·] 括号里的变量整体替换成 Mn。

07因果性slide 19–20

因果系统（causal system）的输出只依赖现在与过去的输入，不能“预知未来”。实时系统必须因果；离线处理（如对整段录音做处理）可以非因果。

例 1　延迟系统 y[n] = x[n − nd]

nd ≥ 0 ⟹ 因果（真正“延迟”） nd < 0 ⟹ 非因果（超前，要用到未来样本）

例 2　滑动平均系统的因果条件slide 20

y[n] = 1M1 + M2 + 1M2∑k = −M1x[n − k]

求和项是 x[n − k]，当 k < 0 时 n − k > n，就是在用未来的样本。要因果，必须让所有索引满足 k ≥ 0：

−M1 ≥ 0  and   M2 ≥ 0
结论：在 M1, M2 取非负值的约定下，因果 ⟺ M1 = 0（只对现在和过去求平均）。若 M1 > 0，窗口伸进未来，系统非因果。
判因果的统一思路：因果性其实是关于冲激响应支撑集的条件 —— 第 12 节会证明，LTI 系统因果 ⟺ h[n] = 0, ∀n < 0。上面滑动平均的结论，用 h[n] 描述就是 h[n] 只在 −M1 ≤ n ≤ M2 非零，所以 M1 = 0 时起点才落在 n = 0。

08BIBO 稳定性slide 20–22

BIBO = Bounded Input, Bounded Output：任何有界输入都产生有界输出，系统才叫 BIBO 稳定。

|x[n]| ≤ Bx < ∞  for all n ⟹  |y[n]| ≤ By < ∞  for all n
Bx, By 为有限正常数

例 1　平方系统 y[n] = (x[n])2 —— 稳定

|x1[n]| ≤ Bx < ∞ ⟹ |y1[n]| = |x1[n]|2 ≤ Bx2 = By < ∞

例 2　y[n] = log10(x[n]) —— 不稳定

取有界输入 x[n] = 0，则 y[n] = log100 → −∞。有界输入产生了无界输出，所以不 BIBO 稳定。

例 3　累积系统 —— 不稳定

y[n] = n∑k = −∞x[k]，取 x[n] = u[n] y[n] = n∑k = −∞u[k] = 0,    n < 0n + 1, n ≥ 0 n → ∞ ⟹ y[n] → ∞
结论：阶跃输入有界（|x[n]| ≤ 1），输出却是无界的斜坡 n + 1 ⟹ 累积系统不 BIBO 稳定。
和第 12 节串起来看：累积系统的 h[n] = u[n]，而 ∞∑n = 0|u[n]| = ∞，绝对不可和 ⟹ 不稳定。判稳定的两种方法（定义法、h[n] 绝对可和）结论一致。

09记忆性（无记忆 / 有记忆）slide 22–23

无记忆（memoryless）系统：n 时刻的输出只依赖同一时刻的输入 x[n]，不碰其他时刻。

系统类别理由
y[n] = n∑k = −∞x[k]有记忆要累加全部过去样本
y[n] = (x[n])2无记忆只用 x[n] 本身
y[n] = x[n − n0]有记忆（n0 ≠ 0）取的是另一时刻的输入
y[n] = x[n − 0] = x[n]无记忆（n0 = 0）退化为恒等系统
四个性质互不包含：累积系统同时是线性、时不变、有记忆、不稳定的。考试里常要求给一个系统逐条判定，务必分开判断，别用一个性质的结论推另一个。

10冲激响应与卷积slide 23–26

这是全章的核心：对 LTI 系统，只要知道它对一个冲激的响应 h[n]，就能算出它对任何输入的响应——因为任何信号都能拆成一串加权平移的冲激。

什么是冲激响应

把 δ[n] 加到 LTI 系统输入端，输出就叫该系统的冲激响应（impulse response），记作 h[n]：

定义x[n] = δ[n]→LTI→y[n] = h[n]

任意序列的冲激分解slide 23–24

x[n] = ∞∑k = −∞x[k] δ[n − k]

每个 x[k] 是系数，δ[n − k] 负责把它搬到位置 k。课件用第 1 节那个例子演示：

x[n] = 1.6 δ[n + 2] + 1.8 δ[n] − 1.5 δ[n − 3]

卷积和（convolution sum）slide 24

卷积x[n]→h[n]→y[n]
y[n] = x[n] ∗ h[n] = ∞∑k = −∞x[k] h[n − k] = ∞∑k = −∞h[k] x[n − k]
为什么这两行相等：第 2 行只是把第 1 行的求和变量 k 换成了 n − k（哑变量重命名），这说明卷积可交换。这也是为什么“把 h 翻转再平移”和“把 x 翻转再平移”结果一样 —— 手算卷积时选较短的那个来翻转最省事。

卷积的三个代数性质slide 25

1) 交换律　x[n] ∗ h[n] = h[n] ∗ x[n] 2) 分配律　x[n] ∗ [h1[n] + h2[n]] = x[n] ∗ h1[n] + x[n] ∗ h2[n] 3) 结合律　(x[n] ∗ h1[n]) ∗ h2[n] = x[n] ∗ (h1[n] ∗ h2[n])

并联与级联的等效系统slide 26

并联 (a)x[n]→h1[n]→+→y[n]
　x[n]→h2[n]↗+→y[n]
等效 (b)x[n]→h1[n] + h2[n]→y[n]

(a) 两个 LTI 系统并联 → (b) 等效为单个系统，冲激响应相加（分配律）

级联 (a)x[n]→h1[n]→h2[n]→y[n]
(b)x[n]→h2[n]→h1[n]→y[n]
等效 (c)x[n]→h1[n] ∗ h2[n]→y[n]

(a) 级联 → (b) 顺序可交换（交换律）→ (c) 等效为单个系统，冲激响应卷积（结合律）

工程含义：级联的总冲激响应是各级 h 的卷积，与顺序无关。所以一条“先差分再平滑”的链路可以随意调换次序甚至合并成一级 —— 第 13 节的可逆系统、Chapter 8/9 的滤波器级联都靠这条。

11五种基本 LTI 系统的 h[n]slide 27–29

把 δ[n] 打进系统，直接读出 h[n]。这五个是把差分方程、卷积、稳定性串起来的“标准零件”。

系统时域关系冲激响应 h[n]稳定 / 因果
延迟 Delay y[n] = x[n − nd] h[n] = δ[n − nd] 恒稳定；nd ≥ 0 才因果
滑动平均
Moving average		 y[n] = 1M1+M2+1M2∑k = −M1x[n−k] h[n] = 1M1+M2+1M2∑k = −M1δ[n−k]
= 1/(M1+M2+1),  −M1 ≤ n ≤ M20,  otherwise		 恒稳定（Σ|h| = 1）；M1 = 0 才因果
累积
Cumulative / accumulator		 y[n] = n∑k = −∞x[k] h[n] = n∑k = −∞δ[k] = u[n] 不稳定；因果
前向差分
Forward difference		 y[n] = x[n + 1] − x[n] h[n] = δ[n + 1] − δ[n] 稳定；非因果（用了 x[n+1]）
后向差分
Backward difference		 y[n] = x[n] − x[n − 1] h[n] = δ[n] − δ[n − 1] 稳定；因果
滑动平均的 h[n] 怎么来的：把 δ[n−k] 的代数和写成“在区间内取常数值”的形式。因为 δ[n−k] 只在 n = k 非零，而 k 遍历 −M1 … M2，所以 h[n] 在 −M1 ≤ n ≤ M2 内恒为 1/(M1+M2+1)，其余为 0，长度共 M1+M2+1 个。

12只用 h[n] 判定稳定与因果slide 29–33

这两个判据是本课程最常用的“一行判定”，必须背下来并能对着 h[n] 的表达式或图形直接下结论。

稳定（BIBO）：∞∑k = −∞|h[k]| < ∞ 因果：h[n] = 0  for  n < 0

稳定性判据的等价说法：|x[n]| ≤ Bx < ∞ ⟹ |y[n]| ≤ By < ∞ ⟺ ∞∑k=−∞|h[k]| < ∞，即 h[n] 绝对可和。

例 1　延迟系统 h[n] = δ[n − nd]slide 30

稳定：∞∑n = −∞|δ[n − nd]| = 1 < ∞ ✓ 因果：nd ≥ 0 ⇒ 因果；nd < 0 ⇒ 非因果

例 2　滑动平均slide 31

h[n] 只在有限区间 −M1 ≤ n ≤ M2 非零（有限支撑），因此

∞∑n = −∞|h[n]| = 1 < ∞  ⟹   BIBO 稳定

因果性：M1 = 0（且 M2 ≥ 0）时 h[n] = 0, ∀n < 0，因果；M1 > 0 时用了未来样本，非因果。

例 3　前向差分 h[n] = δ[n + 1] − δ[n] —— 稳定但非因果slide 32

∞∑n = −∞|h[n]| = 2 < ∞ ⟹ BIBO 稳定 但 h[−1] = 1 ≠ 0 ⟹ 非因果

物理意义：δ[n + 1] 对应 x[n + 1]，要用到下一拍的输入。

例 4　后向差分 h[n] = δ[n] − δ[n − 1] —— 稳定且因果slide 32

冲激响应有限、绝对可和，且 n < 0 时 h[n] = 0 ⟹ 稳定 + 因果。

非因果 FIR 怎么救：加延迟slide 33

结论（课件原话）：任何非因果 FIR 系统都可以通过施加足够的延迟变成因果系统。

把“前向差分”级联一个“单位延迟” h2[n] = δ[n − 1]：

h1[n] ∗ h2[n] = (δ[n+1] − δ[n]) ∗ δ[n−1] = δ[n−1] ∗ (δ[n+1] − δ[n]) = δ[n − 1 + 1] − δ[n − 1 + 0]  （δ[n−a]∗δ[n−b] = δ[n−a−b]） = δ[n] − δ[n − 1]  ←  因果的后向差分
用的什么性质：
① δ[n − a] ∗ δ[n − b] = δ[n − a − b]（冲激卷积的“位置相加”）
② 卷积交换律 / 结合律 —— 所以“先差分再延迟”等于“延迟后差分”。
③ 这就是课件为什么强调延迟系统的 h[n]：延迟是最简单的“因果化”工具。

13可逆系统slide 34–35

系统 T 可逆，指存在 T−1 能把输出还原成原来的输入：级联 T 与其逆系统后，整体必须是恒等系统。

可逆x[n]→h[n]
T→hi[n]
T−1→x[n]
y[n] = T{x[n]},  T−1{y[n]} = T−1{T{x[n]}} = x[n] h[n] ∗ hi[n] = δ[n]

例　h2[n] = δ[n] − δ[n−1] 是不是 h1[n] = u[n] 的逆？slide 35

h[n] = h1[n] ∗ h2[n] = u[n] ∗ (δ[n] − δ[n−1]) = u[n] ∗ δ[n] − u[n] ∗ δ[n−1] = u[n] − u[n−1] = δ[n]  ✓
结论：h2[n] 是 h1[n] 的逆系统。
一句话记住：累积（求和）的逆是差分，延迟的逆是超前。这条和第 2 节 δ[n] = u[n] − u[n−1] 是同一件事的两种说法。

14线性常系数差分方程 LCCDEslide 36–38

一大类重要的 LTI 系统，其输入输出的关系可以写成N 阶线性常系数差分方程（Linear Constant-Coefficient Difference Equation）。这是后面 Chapter 3（z 变换）、Chapter 5–7（滤波器实现）的出发点。

(2.84) N∑k = 0ak y[n−k]  =  M∑m = 0bm x[n−m]

把累积器写成 LCCDEslide 36

y[n] = n∑k = −∞x[k] = x[n] + n−1∑k = −∞x[k] 而 y[n−1] = n−1∑k = −∞x[k] ⟹ y[n] = x[n] + y[n−1]  ⟺  y[n] − y[n−1] = x[n] ⟹ N = 1,  a0 = 1,  a1 = −1,  M = 0,  b0 = 1
累积器x[n]→+→y[n] ↺1 拍延迟→y[n−1]→＋

因果形式（递推解）slide 37

因果系统不能依赖未来的输入，所以把 a0y[n] 单独留下，其余项移到右边：

a0y[n] + N∑k = 1aky[n−k] = M∑m = 0bmx[n−m] ⟹  y[n] = − N∑k = 1aka0y[n−k] + M∑m = 0bma0x[n−m]
初始静止（initial rest）：LCCDE 的解需要初始条件。课件明确：对上述 LCCDE，零初始条件下零输入产生零输出——这才定义了因果解，否则同一个差分方程可对应多个系统（这也是 Chapter 3 单向/双向 z 变换区分的原因）。

特例：因果 FIR（N = 0）slide 38

y[n] = M∑m = 0bma0x[n−m] x[n] = δ[n] ⟹ h[n] = M∑m = 0bma0δ[n−m] ⟹ h[n] = bn / a0,   n = 0, 1, …, M0,   otherwise
要点：N = 0（没有输出反馈）时冲激响应只有 M+1 个非零值 ⟹ FIR（finite impulse response），必然稳定。含 N ≥ 1 的反馈项时冲激响应一般无限长 ⟹ IIR，稳定性要看系数（Chapter 3 的极点位置）。这也解释了为什么累积器（IIR）不稳定。

Q5

由四组输入–输出对反推系统性质与 h[n]

Four input–output pairs of system S (Figure 1), then questions (a)–(d).

四组对应的数学表达：

配对输入 xi[n]输出 yi[n]
(1)x1[n] = δ[n] + 2δ[n−1] + δ[n−2]y1[n] = δ[n] + δ[n−3] + δ[n−4]
(2)x2[n] = δ[n] + δ[n−2]y2[n] = δ[n−1] + 2δ[n−3] + δ[n−5]
(3)x3[n] = δ[n−1] + δ[n−2]y3[n] = δ[n−2] + δ[n−3] + δ[n−4] + δ[n−5]
(4)x4[n] = δ[n]y4[n] = δ[n] + δ[n−1]
a系统 S 可能是时不变的吗？

时不变要求 x[n] → y[n] 蕴含 x[n−n0] → y[n−n0]。要否定时不变性，需要找到两个输入，其中一个是另一个的移位，而它们的输出却没有相同的移位。

检查四个输入：

x1 = δ[n] + 2δ[n−1] + δ[n−2],  x2 = δ[n] + δ[n−2],  x3 = δ[n−1] + δ[n−2],  x4 = δ[n]

没有任何一个输入是另一个的移位版本（形状各不相同：x1 是 [1,2,1]，x2 是 [1,0,1]，x3 是移位后的 [1,1]，x4 是单个冲激）。因此这四组数据不构成对时不变性的反例。

答案：可以是时不变的。
教学点“没有反例” ≠ “已证明”。准确的说法是：给定数据不排除时不变性。这道题问的是“can be”，所以回答 Yes；如果问“is it”，则只能说“无法确定”。
b系统 S 可能是线性的吗？

线性要求：若 xa → ya、xb → yb，则任何线性组合满足 a xa + b xb → a ya + b yb。所以先找四输入之间的线性关系。计算：

x1[n] + x2[n] = [δ[n]+2δ[n−1]+δ[n−2]] + [δ[n]+δ[n−2]] = 2δ[n] + 2δ[n−1] + 2δ[n−2]

再看另一侧：2x3[n] = 2δ[n−1] + 2δ[n−2]，2x4[n] = 2δ[n]，于是

2x3[n] + 2x4[n] = 2δ[n] + 2δ[n−1] + 2δ[n−2] ⟹  x1[n] + x2[n] = 2x3[n] + 2x4[n]

若系统线性，输出必须满足 y1[n] + y2[n] = 2y3[n] + 2y4[n]。逐项核对：

左边　y1 + y2 = [δ[n]+δ[n−3]+δ[n−4]] + [δ[n−1]+2δ[n−3]+δ[n−5]] = δ[n] + δ[n−1] + 3δ[n−3] + δ[n−4] + δ[n−5]
右边　2y3 + 2y4 = [2δ[n−2]+2δ[n−3]+2δ[n−4]+2δ[n−5]] + [2δ[n]+2δ[n−1]] = 2δ[n] + 2δ[n−1] + 2δ[n−2] + 2δ[n−3] + 2δ[n−4] + 2δ[n−5]

两者明显不等（左边在 n=0 系数是 1 不是 2，右边在 n=2 有 2 而左边没有）：

y1[n] + y2[n] ≠ 2y3[n] + 2y4[n]
答案：不可能线性——叠加性质被违反。
教学点找线性关系的套路：四输入都是 δ 的稀疏组合，把它们写成向量 [c0, c1, …]，再解 α1x1 + α2x2 = α3x3 + α4x4。不要只试 x1 + x2 一种组合——本题恰好是这个组合成功。
c若 (2)(3) 属于一个已知 LTI 系统 S2，求 h[n]

对 LTI 系统 δ[n] → h[n]，所以 δ[n−2] → h[n−2]。由 (2)：

x2[n] = δ[n] + δ[n−2]  ⟹  y2[n] = h[n] + h[n−2] y2[n] = δ[n−1] + 2δ[n−3] + δ[n−5]

把这个输出因式分解成卷积形式（观察两端的 δ[n−1] 与 δ[n−5]，中间的系数 2 来自重叠）：

[δ[n]+δ[n−2]] ∗ [δ[n−1]+δ[n−3]] = δ[n−1] + δ[n−3] + δ[n−3] + δ[n−5] = δ[n−1] + 2δ[n−3] + δ[n−5]

与 y2 完全一致，故

h[n] = δ[n−1] + δ[n−3]

用 (3) 验证。由 x3[n] = δ[n−1] + δ[n−2] 得 y3[n] = h[n−1] + h[n−2]，而

h[n−1] = δ[n−2] + δ[n−4],   h[n−2] = δ[n−3] + δ[n−5] ⟹ y3[n] = δ[n−2] + δ[n−3] + δ[n−4] + δ[n−5]  ✓
答案：h[n] = δ[n−1] + δ[n−3]（与 (3) 完全吻合）。
教学点从“输入含 δ[n]”的那一对最容易读出 h：输出的 δ 系数序列就是 h 与输入系数序列的卷积。这里已知输入和输出，做“反卷积”即可；x2 的系数是 [1,0,1]，输出 [0,1,0,2,0,1]。
d若 (1) 属于 LTI 系统 S3，求 Figure 2 输入的输出

已知 (1)：x1[n] = δ[n] + 2δ[n−1] + δ[n−2] 产生 y1[n] = δ[n] + δ[n−3] + δ[n−4]。

新输入是“两个 x1 错开 2 拍相加”：

x1[n−2] = δ[n−2] + 2δ[n−3] + δ[n−4] x1[n] + x1[n−2] = δ[n] + 2δ[n−1] + 2δ[n−2] + 2δ[n−3] + δ[n−4] = x[n]  ✓

所以 x[n] = x1[n] + x1[n−2]。由时不变性 x1[n−2] → y1[n−2]，再由线性叠加：

y[n] = y1[n] + y1[n−2]
y1[n] = δ[n] + δ[n−3] + δ[n−4] y1[n−2] = δ[n−2] + δ[n−5] + δ[n−6] ⟹ y[n] = δ[n] + δ[n−2] + δ[n−3] + δ[n−4] + δ[n−5] + δ[n−6]
答案：y[n] = 1,  n = 0, 2, 3, 4, 5, 60,  otherwise，即 y[0]=y[2]=y[3]=y[4]=y[5]=y[6]=1，其余为 0。注意 y[1] = 0。
教学点这类题的核心动作是把新输入表示为已知输入的线性组合（含移位），然后直接搬用已知的输入–输出对。原文解答中夹了一行与本问无关的 2y3+2y4 公式（属上问残留），已略去
