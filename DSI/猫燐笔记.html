1 · MOS 作负载的框架

这一章定三件事：负载为什么必须换成 MOS 管、MS 与 ML 各管什么、以及后面每一节都要用到的开关判据与三区公式。

1.1 负载为什么不用电阻

电阻负载反相器的下拉管 MS 决定输出低电平，上拉电阻 RD 决定输出高电平。片上做这样一个电阻，要用一条长条多晶硅（或扩散区）实现，电阻值由几何尺寸定：

(1.1) R = ρ · Lt W ← 方块电阻的基本关系：长度在分子、厚度与宽度在分母

（1.1）里 ρ 是材料电阻率、t 是膜厚、L/W 是长宽比。要让 R 大，只能把 L/W 做长。把（1.1）两边同乘 W、同除 R，解出长度比：

(1.2) LW = R tρ ← （1.1）两边乘 W/(R t) = (95×103 Ω)(1×10−4 cm)1×10−3 Ω·cm ← 代入 R = 95 kΩ、t = 1 µm、ρ = 0.001 Ω·cm = 9.51×10−3 ← 分子乘出（Ω·cm 与 Ω·cm 约掉，无量纲） = 9500 ← 除法

9500 意味着这条电阻要 9500 个方块长。而同一条支路上的 MS，W/L 只要 1 量级（§2.3 算出 1.03）。面积之比就是量级之比：电阻 L·W = L²/9500，MOS 管 L·W = 1.03 L²，两者差约 104 倍。这就是负载必须换成 MOS 管的原因——不是电学上的需要，而是面积上的。

注意块：换掉电阻之后，电路的性质变了

把 RD 换成 ML 之后，上拉支路不再是"电流随电压线性变化"，而是一条有阈值、有饱和段的 MOSFET 特性曲线。后果有两处： ① 输出高电平不再一定是 VDD（饱和型负载会掉一个阈值）；② 上拉能力随输出电压变化，充放电时间不再对称。后面 §3、§6 各处理一处。

1.2 MS 与 ML 的分工

笔记把"有效定义"写在一句话里：MS 可以随 VIN 切换模式，但 ML 必须永远导通。 这条要求不是风格问题，而是能不能工作的分界线。

ML 若一旦关断，输出节点与 VDD 之间就没有任何直流通路。此时输出电平由节点电容上残留的电荷决定，与输入无关：输入回到低电平时，输出无法被拉回高电平，高电平这个"逻辑值"就消失了。所以 ML 必须是常通的——这是 §3 里筛选六种接法的唯一标准。

1.3 开关判据（NMOS / PMOS）

判据只看栅源电压与阈值的关系，与漏源电压无关：

器件导通（ON）截止（OFF）
NMOSVGS > VTNVGS ≤ VTN
PMOSVSG > |VTP|VSG ≤ |VTP|

两条判据形状相同，差别只在"栅源"的定义方向：NMOS 要求栅高于源，PMOS 要求源高于栅。伪 NMOS 里的负载管是 PMOS，源极接 VDD、栅极接地，于是 VSG = VDD − 0 = VDD，恒大于 |VTP|，天然常通——这正是它被选作负载的原因（§3.5）。

易错点：导通、饱和、线性是三个互相独立的问题

错误形态：看到 "VGS > VTN" 就套饱和区公式 ID = K(VGS − VTN)²。

正确形态：先用（1.3）判"通不通"，通不通确定之后，再用 VDS 与 VOV 的大小判"在哪个区"，最后才选公式。VGS > VTN 只说明沟道出现了，不说明沟道是否被夹断。

1.4 三个工作区与 Ron

三个区的电流式用 K 写出来只有两条（截止区电流为零）：

(1.3) 截止： ID = 0 条件 VGS ≤ VTN 饱和： ID = K VOV² 条件 0 < VOV ≤ VDS 三极管： ID = K [ 2VOVVDS − VDS² ] 条件 0 < VDS < VOV

饱和式里没有 ½：它已经被折进 K 了。饱和式说明电流只由过驱动电压决定，与 VDS 无关——这就是"恒流"的来源，也是负载管能当"电流源"用的原因。三极管式里两项的相对大小是 2VOV 比 VDS：当

(1.4) VDS ≪ 2VOV ← 三极管区深到"电阻"的那一段

时，VDS² 项比 2VOVVDS 小一个 VDS/(2VOV) 的因子，可以扔掉，三极管式退化成线性式：

(1.5) ID = K[2VOVVDS − VDS²] ≈ K (2VOV) VDS ← 扔掉 VDS² 项（条件见 1.4 式）

此时 ID 与 VDS 成正比，比值就是电阻，取倒数即得开关管的导通电阻：

(1.6) Ron ≡ VDSID = VDSK(2VOV)VDS ← 代入（1.5）式 = 12K VOV ← 上下约掉 VDS

（1.6）说的是：Ron 与过驱动电压成反比。输入越高、阈值越低、管子越宽（K 越大），导通电阻越小。量纲也可以校对：K 是 A/V²，乘上 V 得 A/V，取倒数得 V/A = Ω，成立。

近似块：Ron 的适用范围与误差

（1.6）建立在扔掉 VDS² 项之上。误差正是因子 VDS/(2VOV)：VOV = 1.9 V、VDS = 0.2 V 时，误差 0.2/3.8 = 5.3%，扔得掉；VOV = 0.5 V、VDS = 0.2 V 时，误差 20%，扔不得，必须回到（1.3）的三极管式解二次方程。

2 · 电阻负载反相器：全篇的基准

后面四种 MOS 负载的性能都要拿"电阻 + MS"这个最原始的反相器作对照。这一章把这台基准机器的两个电平、一个边界和一条设计流程算清楚。

2.1 两个状态与电平

导通时的输出低电平，由 RD 与 Ron 的分压决定：

(2.1) VL = VDD · RonRon + RD ← 串联分压：同一电流，电压按电阻分配

（2.1）的物理含义在比值 Ron/RD 上：这个比值占几成，输出低电平就占 VDD 的几成。要 VL 足够低（逻辑 0），必须 Ron ≪ RD。而 RD 又要足够大才能把导通时的功耗压下来——这两条合起来就是"低功耗 + 低电平"的固有矛盾，也是 §3 换负载拓扑的动机之一。

关断态没有电流，RD 上没有压降，于是

(2.2) VH = VOH = VDD − IDRD ← 上拉支路的欧姆定律 = VDD − 0 ← ID = 0 = VDD

2.2 VIL = VTN 的来历

输入从 0 往上加，在 VIN 还没到 VTN 之前，MS 一直是截止的：没有电流，输出一直停在 VDD，无论输入怎么变。输入一旦超过 VTN，沟道出现、电流开始流、输出开始下降。所以"输出开始偏离高电平"的那个输入值，就是阈值电压本身：

(2.3) VIL = VTN ← 理想情形（MS 一导通就把输出拉离 VDD）

这是一条"理想情形"的结论，成立的前提有两个：一是电阻负载的电流不随输出变化（真电阻），二是判据用硬阈值（忽略亚阈值导电）。笔记在这里标了一句"实际由于 ML 会导致部分变化"：一旦上拉支路换成 MOS 管，它的电流会随 VOUT 变化，转折点就从 VTN 上挪一点。

2.3 设计示例（课件数值复算）

题目：VDD = 3.3 V，输出低电平时功耗 P = 0.1 mW、此时 VL = 0.2 V；K′N = 60 µA/V²，VTN = 0.75 V、λ = 0。求 RD 与 MS 的 W/L。

低电平状态的功耗全部落在电源到地的通路上，所以电流由功耗与电源电压定：

(2.4) IDD = PVDD ← 功耗定义 P = VDDIDD 两边除 VDD = 0.1×10−3 W3.3 V ← 代入 P、VDD = 30.3 µA ← 除法（1 W/V = 1 A）

低电平状态下 RD 两端的电压是 VDD − VL，流过它的就是上面这个电流：

(2.5) RD = VDD − VLIDD ← 欧姆定律 = 3.3 − 0.230.3×10−6 ← 代入（单位：V / A = Ω） = 3.130.3×10−6 ← 分子相减 = 102 kΩ ← 除法

再定 W/L。此时 VGS = 3.3 V、VDS = 0.2 V，过驱动 VOV = 3.3 − 0.75 = 2.55 V，而 VDS = 0.2 V < 2.55 V，所以 MS 在三极管区。用（1.3）的三极管式，把 KS 当未知量解出来：

(2.6) IDD = KS[ 2VOVVDS − VDS² ] ← （1.3）三极管式 30.3×10−6 = KS[ 2(2.55)(0.2) − (0.2)² ] ← 代入 IDD、VOV、VDS 30.3×10−6 = KS[ 1.02 − 0.04 ] ← 括号内两项各自乘出 30.3×10−6 = KS(0.98) ← 括号内相减 KS = 30.9 µA/V² ← 两边除 0.98（单位 A/V）

再由 K 的定义反解尺寸：

(2.7) WL = 2KSK′N ← K ≡ ½K′N(W/L) 两边乘 2、除 K′N = 2(30.9×10−6)60×10−6 ← 代入 KS、K′N（A/V² 约掉，无量纲） = 1.03 ← 除法

与课件给出的 30.3 µA、102 kΩ、1.03 三处一致。注意最后这个 1.03 与 §1.1 的 9500 是同一个电路里两个支路的尺寸比——这就是电阻负载在 IC 里活不下去的量化证据。

2.4 输出低电平的另一种算法：Ron

如果只知道 Ron 而不想解二次方程，（1.6）给出一个捷径。用（2.7）的尺寸算回 KS = ½(60)(1.03) = 30.9 µA/V²，则

(2.8) Ron = 12KSVOV ← （1.6）式 = 12(30.9×10−6)(2.55) ← 代入 = 1157.6×10−6 ← 分母乘出 = 6.35 kΩ ← 取倒数

代回（2.1）验算低电平：VL = 3.3 × 6.35/(6.35 + 102) = 3.3 × 0.0586 = 0.193 V，与题给的 0.2 V 差 3.4%。这点差就是 §1.4 里扔掉的 VDS² 项造成的（误差因子 0.2/(2×2.55) = 3.9%）。两处独立的算法互相对上，说明（1.6）在这里可用。

3 · 六种 MOS 负载接法

把 RD 换成一只 MOS 管之后，栅极接哪里决定了这只管子在整个工作范围内是什么状态。这一章按笔记的顺序把六种接法逐一过一遍：两种恒关断（不可用）、四种恒导通（可用）。

3.1 两种恒关断接法（不可用）

接法 ①：栅极接源极。 栅、源同电位，栅源电压恒为零：

(3.1) VGS,L = VG,L − VS,L ← 栅源电压的定义 = VOUT − VOUT ← 栅、源接在同一节点（输出节点） = 0 ← 相减

对增强型管子 VTN = 0.6 V > 0，由（1.3）的截止条件 VGS ≤ VTN 得 ML 恒截止。上拉支路断开，输出只剩节点电容，高电平无从建立。

接法 ②：栅极接地。 源极在输出节点上，电位 ≥ 0，于是：

(3.2) VGS,L = VG,L − VS,L ← 定义 = 0 − VOUT ← 栅接地，源接输出 = −VOUT ← 减法

输出电平非负，故 VGS,L ≤ 0 < VTN，同样恒截止。两种接法的失败原因是同一个：栅源之间没有正电压差，沟道不出现。

关键块：筛选六种接法的唯一硬指标

① ② 与 ③ ④ ⑤ ⑥ 的唯一区别，不是"接法好看不好看"，而是负载管的 VGS 在整个输出摆幅内是否始终大于 VTN。① ② 的 VGS ≤ 0，直接出局；③ 用负阈值、④ ⑤ 用栅压在 VDD 以上、⑥ 用 PMOS 的源栅差，都是为了让 ML 在整个摆幅内保持导通。

3.2 耗尽型负载（栅接源，但阈值是负的）

接法与 ① 完全相同——栅、源短接，VGS,L = 0。区别在器件：耗尽型 NMOS 的阈值是负的（例题里 VTN,L = −1 V），所以过驱动电压仍然是正的：

(3.3) VOV,L = VGS,L − VTN,L ← 过驱动的定义 = 0 − (−1 V) ← 代入 VGS,L = 0、VTN,L = −1 V = 1 V ← 减法

因为 VOV,L = 1 V 与输出无关（栅源短接，VGS 恒为 0），所以只要 ML 在饱和区，它的电流就是一个常数。判饱和用（1.3）的条件 VDS ≥ VOV：

(3.4) VDS,L = VDD − VOUT ← 漏在 VDD、源在输出 VDS,L ≥ VOV,L ⇔ VDD − VOUT ≥ 1 V ← 代入（3.3）的 1 V

输出一旦升到 VDD − 1 V 以上，ML 离开饱和区进入三极管区，电流随 VDS,L 减小而减小，并在 VOUT = VDD 时正好为零。所以耗尽型负载的高电平可以顶到电源电压：

(3.5) VH = VDD ← VOUT = VDD 时 ID = 0，负载不再有压降

饱和区内的电流是个与输出无关的常数：

(3.6) IDL = KL VOV,L² ← （1.3）饱和式 = KL (1 V)² ← 代入（3.3） = KL ← 乘方；单位 A/V² × V² = A

（3.6）右侧不含 VOUT，这正是笔记写的"饱和电流恒定"。它带来的直接后果是：低电平状态下把输出拉低的电流由负载管单方面定死，开关管只需把这个电流吞下去并保持在三极管区。

近似块：耗尽型负载的体效应可以忽略吗

耗尽型负载的源极在输出节点上，体端接地，VSB = VOUT ≠ 0，严格说阈值要按（4.1）修正：VSB = 0.25 V 时 |VTN,L| 从 1.00 V 降到 0.926 V，过驱动从 1.000 V 降到 0.926 V，电流降到原来的 85.8%。习题（Tutorial 4 第 4 题）按 λ = 0、不计体效应的约定给答案，得 (W/L)L = 1.60；计入体效应要 1.87，比它大 17%（见 §4.3）。

3.3 饱和型负载（栅接 VDD）

把负载管的栅极和漏极一起接到 VDD，源极接输出。此时栅源电压与漏源电压是同一个量：

(3.7) VGS,L = VDD − VOUT ← 栅在 VDD、源在输出 VDS,L = VDD − VOUT ← 漏在 VDD、源在输出 ⇒ VDS,L = VGS,L ← 两式相等

饱和的条件是 VDS ≥ VGS − VTN。把（3.7）代进去：

(3.8) VDS,L ≥ VGS,L − VTN,L ← （1.3）的饱和条件 VGS,L ≥ VGS,L − VTN,L ← 用（3.7）把左边的 VDS,L 换掉 0 ≥ −VTN,L ← 两边同减 VGS,L

增强型 VTN,L > 0，所以末行恒成立——笔记写"只要导通，饱和恒成立"。这只管子在整个工作范围内都停在自己特性曲线的饱和段上，是一个两端器件意义上的电流源。

高电平与电阻负载不同了。输出被上拉到多高，取决于负载管能把它顶到哪：当输出接近 VDD 时 VGS,L 趋近 0，沟道消失，电流消失，输出就停在这里。令 MS 关断（IDL = 0）并取（1.3）的饱和式左边为 0，解出的就是 VH：

(3.9) 0 = KL (VDD − VH − VTN,L)² ← （1.3）饱和式 + （3.7），令 IDL = 0 0 = VDD − VH − VTN,L ← 两边开方（只取正根） VH = VDD − VTN,L ← 移项

（3.9）里的 VTN,L 不是常数：此时源极在 VH、体端接地，VSB = VH，阈值要被（4.1）抬高。把（4.1）与（3.9）联立，就得到 VH 的自洽方程，只能迭代或图解法求解：

(3.10) VH = VDD − [ VTN0 + γ( √(2φF + VH) − √(2φF) ) ] ← （4.1）代入（3.9）

把 VDD = 2.5 V、VTN0 = 0.6 V 代进（3.10）做四次迭代，可以看到它很快收敛：

(3.11) VH(0) = VDD − VTN0 = 1.900 V ← 先按无体效应起步 VH(1) = 1.9 − 0.5(√2.500 − √0.600) = 1.497 V ← 代入（3.10），用 VH(0) 算根号 VH(2) = 1.9 − 0.5(√2.097 − √0.600) = 1.563 V ← 用 VH(1) 再算一次 VH(3) = 1.9 − 0.5(√2.163 − √0.600) = 1.552 V ← 第三次 VH(4) = 1.9 − 0.5(√2.152 − √0.600) = 1.554 V ← 第四次，已收敛

收敛到 VH = 1.55 V，小数点后两位已经不动了（1.497 → 1.563 → 1.552 → 1.554 → 1.5535）。把这个值与课件"VH = 1.55 V"对照，一致。

差别有多大：把（3.9）里的 VTN,L 当常数（0.60 V）代入，得 VH = 1.90 V；按（3.10）自洽求解，得 1.55 V，两者差 0.35 V，比一个阈值还多。所以饱和型负载的 VH 不能直接写 VDD − VTN0。

3.4 线性型负载（栅接 VGG）

把负载管的栅极单独接到一个高于 VDD 的电源 VGG 上，漏极接 VDD、源极接输出。此时栅源电压与漏源电压不再相等：

(3.12) VGS,L = VGG − VOUT ← 栅在 VGG、源在输出 VDS,L = VDD − VOUT ← 漏在 VDD、源在输出

线性区的条件是 VDS < VGS − VTN。把（3.12）两式代入，解出 VGG 需要多高：

(3.13) VDD − VOUT < (VGG − VOUT) − VTN,L ← （1.3）线性区条件 + （3.12） VDD < VGG − VTN,L ← 两边同加 VOUT VGG > VDD + VTN,L ← 移项

（3.13）说明为什么线性型负载一定要第二路电源：栅压至少要比 VDD 高出一个阈值，负载管才肯工作在三极管区。管子在三极管区里像个电阻，上拉能力强、速度快，代价是多一路电源和更大的摆幅驱动。

3.5 伪 NMOS（栅接地 PMOS）

把负载管换成 PMOS：源极接 VDD、栅极接地、漏极接输出。判据要用源栅电压：

(3.14) VSG,L = VDD − 0 = VDD ← 源在 VDD、栅接地

对 |VTP| = 0.6 V、VDD = 2.5 V，VSG,L = 2.5 V > 0.6 V，恒导通。饱和条件是 VSD ≥ VSG − |VTP|，即

(3.15) VDD − VOUT ≥ VDD − |VTP| ← 代入 VSD,L 与 VSG,L −VOUT ≥ −|VTP| ← 两边同减 VDD VOUT ≤ |VTP| ← 两边同乘 −1（不等号反向）

也就是说这只 PMOS 只在输出低于 |VTP| 时饱和，输出一旦抬高它就进入三极管区、上拉能力变强——这正好补齐了 NMOS 负载"高电平上不去"的毛病，所以 VH = VDD。

第二个好处是没有体效应。PMOS 做在 n 阱里，体端接 VDD；源极也接 VDD，于是

(3.16) VSB,L = VS,L − VB,L = 2.5 − 2.5 = 0 ← 源、体同接 VDD

体偏为零，阈值不需要修正，（4.1）式退化成 VTN = VTN0。伪 NMOS 的尺寸计算因此比饱和型负载干净：不迭代，一次算完（§4.4）。

4 · 三种恒导通负载的定量设计

第三章只判定了"能不能用"，这一章把"能用"的三条接法（耗尽型、饱和型、伪 NMOS）变成具体尺寸。核心是两步：先把负载管的电流定下来，再让开关管在低电平状态下吞下同一个电流。

4.1 设计流程与体效应

课件的设计流程是五步，笔记把它压成"三板斧"。两者顺序不同，但都绕不开同一件事：低电平状态下的电流是两只管子共同的电流。

步课件五步法笔记三板斧
1由 P 与 VDD 求 IDD = P/VDD判断这一题要不要算体效应
2设 MS 关断，求高电平 VH先算 ML：它的电流式里只有 VL 和阈值，与 MS 无关
3用 VH 作 MS 的栅压，按 IDD 与 VL 求 (W/L)S再解 MS：它在低电平态处于三极管区
4按 IDD 与 VL 求 (W/L)L—
5校验两只管子的工作区假设（VO = VL 时）—

第 1 步里的"判断要不要算体效应"，指的就是下面这条式子。源极电位一旦高于体端（NMOS 的体端接地），耗尽层变宽，要在同样的栅压下维持同样的沟道电荷，就得加更高的栅压——阈值被抬高：

(4.1) VTN = VTN0 + γ [ √(2φF + VSB) − √(2φF) ]

（4.1）里 VTN0 是源体同电位时的阈值，γ 是体效应系数（单位 V½，就是为配平两个根号而生的），2φF 是表面势参数。VSB = 0 时两个根号相等，第二项为零，退化成 VTN = VTN0——这就是伪 NMOS 可以不算体效应的原因（§3.5）。

代入本讲例题的参数（VTN0 = 0.6 V、γ = 0.5 V½、2φF = 0.6 V、VSB = 0.2 V）：

(4.2) VTN = 0.6 + 0.5(√(0.6 + 0.2) − √0.6) ← 代入（4.1）各参数 = 0.6 + 0.5(√0.8 − √0.6) ← 根号内相加 = 0.6 + 0.5(0.8944 − 0.7746) ← 两个根号各自求值 = 0.6 + 0.5(0.1198) ← 括号内相减 = 0.6 + 0.0599 ← 乘法 = 0.66 V ← 加法（保留两位有效数字）

0.0599 V 看着小，但它落在 (VGS − VTN)² 里：本例题的过驱动是 1.64 V，阈值抬高 0.06 V 相当于过驱动缩小 3.7%，电流因此偏小 7.2%。所以饱和型负载的负载管尺寸必须用 0.66 V 而不是 0.60 V 去算；用错了，W/L 会偏小 7%。

4.2 饱和型负载设计（笔记例题）

题目：VDD = 2.5 V、VL = 0.2 V、低电平态电流 IDD = 80 µA、K′N = 100 µA/V²、VTN0 = 0.6 V、γ = 0.5 V½、2φF = 0.6 V、λ = 0。求两只管子的 W/L。（IDD = 80 µA 对应 P = 0.2 mW：80 µA × 2.5 V = 0.2 mW。）

第一步：高电平。 MS 关断时负载管电流为零，用（3.11）的迭代结果：

(4.3) VH = 1.55 V ← （3.11）的自洽解

第二步：负载管的阈值。 低电平状态下负载管源极在 VL = 0.2 V、体端接地，故 VSB = 0.2 V，用（4.2）：

(4.4) VTN,L = VTN0 + γ(√(2φF + VL) − √(2φF)) ← （4.1），VSB = VL = 0.66 V ← （4.2）的计算

第三步：负载管尺寸。 负载管栅、漏都在 VDD，源极在 VL，故 VGS,L = 2.5 − 0.2 = 2.3 V，由（3.8）它恒饱和。用（1.3）的饱和式：

(4.5) IDL = KL(VGS,L − VTN,L)² ← （1.3）饱和式 80×10−6 = KL(2.3 − 0.66)² ← 代入 IDL、VGS,L、VTN,L 80×10−6 = KL(1.64)² ← 括号内相减 80×10−6 = KL(2.690) ← 平方 KL = 29.7 µA/V² ← 两边除 2.690
(4.6) WLL = 2KLK′N ← K ≡ ½K′N(W/L) = 2(29.7×10−6)100×10−6 ← 代入 = 0.59 ← 除法

第四步：开关管尺寸。 低电平状态下 MS 的 VDS = VL = 0.2 V。栅压取决于输入高电平是多少，这里有两种情况。

情况 A：输入高电平 = VDD（输入由理想满摆幅信号驱动）：

(4.7) IDS = KS[2(VGS,S − VTN,S)VDS − VDS²] ← （1.3）三极管式 80×10−6 = KS[2(2.5 − 0.6)(0.2) − (0.2)²] ← 代入 VGS,S = 2.5、VTN,S = 0.6、VDS = 0.2 80×10−6 = KS[2(1.9)(0.2) − 0.04] ← 括号内两处各自算 80×10−6 = KS[0.76 − 0.04] ← 乘出 80×10−6 = KS(0.72) ← 相减 KS = 111 µA/V² ← 两边除 0.72
(4.8) WLS = 2(111×10−6)100×10−6 = 2.22 ← （2.7）的同一套算法

情况 B：输入高电平 = VH（输入由同结构的上一级驱动）：

(4.9) 80×10−6 = KS[2(1.55 − 0.6)(0.2) − (0.2)²] ← （4.7）第二行，VGS,S 换成 1.55 80×10−6 = KS[2(0.95)(0.2) − 0.04] ← 括号内相减 80×10−6 = KS[0.38 − 0.04] ← 乘出 80×10−6 = KS(0.34) ← 相减 KS = 235 µA/V² ← 两边除 0.34

于是 (W/L)S = 2(235×10−6)/(100×10−6) = 4.71。

易错点：VGS,S 到底取 VDD 还是 VH

错误形态：算完 VH = 1.55 V，转头写 VGS,S = VIN = VDD = 2.5 V，得到 (W/L)S = 2.22。

正确形态：先问"这个门的输入是谁给的"。若输入来自同结构的饱和型负载反相器，输入高电平就是上一级的 VH = 1.55 V，(W/L)S = 4.71；若输入来自理想满摆幅源（外部信号、或上一级是耗尽型/伪 NMOS 负载），才取 2.5 V，得 2.22。

两个数差 2.1 倍，差别全部来自 VGS,S − VTN,S 从 1.90 V 掉到 0.95 V。饱和型负载的输入高电平被自己的 VH 限制住，是这一族电路"逐级变慢"的根源。

第五步：校验假设。 低电平态下两只管子都被假设了工作区，逐一核对：

(4.10) 负载管：VDS,L = 2.3 V，VOV,L = 2.3 − 0.66 = 1.64 V ⇒ VDS,L ≥ VOV,L，饱和 ✓ 开关管：VDS,S = 0.2 V，VOV,S = 1.9 V ⇒ VDS,S < VOV,S，三极管区 ✓

(4.11) IDD = 0.2×10−3 W2.5 V = 80 µA ← （2.4）式，代入 P、VDD

5 · 从反相器到 NAND / NOR

图 2 的六种接法是六个反相器：输入一个变量，输出取反。这一章只改一处——把下拉管 MS 换成多个管子的串并联网络——反相器就升级成 NAND／NOR，负载管的接线一个都不动。

5.1 只动 MS 网络，其余不变

笔记本上的目标是"V、I、P 均不变，串并联的均为 MOS 管"。三件事具体指：

  • V 不变：VH 与 VL 与基准反相器相同。这一点自动成立，因为 VH 由负载管单独决定（§3.2–§3.5），VL 由下拉网络与负载管的电流匹配决定。
  • I 不变：低电平态电流仍是 IDD（例 80 µA）。这一条要求下拉网络在最坏情况下的电阻等于基准反相器的 Ron。
  • P 不变：P = VDDIDD，VDD 与 IDD 没变，功耗自然不变。

所以整章的约束可以压成一句：下拉网络在最坏情况下的等效电阻必须等于基准 Ron。而 Ron 与尺寸的关系是纯几何的，由（1.6）给出：

(5.1) Ron = 12K VOV ← （1.6）式 = 1K′N (W/L) VOV ← 代入 K ≡ ½K′N(W/L)

（5.1）第二行说明 Ron 与 W/L 严格成反比（K′N 与 VOV 都固定）。于是"电阻减半"与"宽度加倍"是同一件事：

(5.2) Ron → Ron2 ⇔ WL → 2WL ← （5.1）中 W/L 加倍则 Ron 减半

5.2 串联得 NAND，并联得 NOR

两个输入 A、B 各控制一只下拉管。串与并的差别只在"什么时候整条支路导通"：

NAND（串联）。 输出为低的条件是两管都导通，此时两只管子的电阻串联相加，必须等于基准值：

(5.3) RA + RB = Ron ← 串联支路电阻相加，等于基准值 2RA = Ron ← 取 RA = RB（两只管子对称） RA = RB = Ron2 ← 两边除 2

再由（5.2），每只管子取 2(W/L)S。

NOR（并联）。 输出为低的条件是任一只管子导通，此时只有那一只在电路里，电阻必须等于基准值：

(5.4) RA = RB = Ron ← 单管导通时承担全部电流

尺寸不必改，每只管子保持 (W/L)S。两管同时导通时并联电阻是 Ron/2，下拉更强、输出更低，属于额外好处而不是设计要求。

把两种结构放在同一尺寸下对照，差别来自串并联本身，与尺寸无关：

(5.5) 串联两只同尺寸管子：R = Ron + Ron = 2Ron ← （5.3）第一行取 RA = RB = Ron 并联两只同尺寸管子：R = Ron RonRon + Ron = Ron2 ← 并联公式 + 分母相加 2RonRon/2 = 4 ← 两者相除，差 4 倍

（5.5）就是笔记里"NAND 与 NOR 可差 4 倍"的来源：同样尺寸下，串联的下拉电阻是并联的 4 倍。反过来说，要让两者都等于基准 Ron，NAND 的每只管子必须加宽一倍（面积 ×2），NOR 的尺寸不用动——这是 NAND 比 NOR 费面积的来源。

5.3 复合门：F = A + B(C + D) 的两种摊法

串并联可以任意嵌套，于是任意"与或式"都能直接摊成一个下拉网络。摊法只有两条：

布尔运算网络结构理由
与（AND）串联串联支路要求全部管子导通，正好是"全真才真"
或（OR）并联并联支路任一管子导通即可，正好是"一真即真"
取反（NOT）由负载管完成下拉网络导通时输出被拉低，故输出 = 网络函数的反

按这三条把 F = A + B(C + D) 摊开：最内层 C+D 是并联；外面乘 B 是串联；再外面加 A 是并联。于是网络是"A 一支"与"B 串 (C∥D) 一支"的并联，共四只管子。笔记在图上标的三层门类型（C,D 取 NOR、B 与 CD 取 NAND、A 与 BCD 取 NOR）说的就是这三层各自的取反。

同一个函数还有另一个摊法。用一次分配律：

(5.6) B(C + D) = BC + BD ← 分配律（一次展开） F = A + BC + BD ← 代回 F 的表达式

（5.6）的形式是三个并联支路：A、BC、BD，五只管子，每个支路内部只有串联。

两个摊法的差别可以逐项列出来：

写法管子数支路结构尺寸怎么定
A + B(C+D)4A ｜ B 串 (C∥D)含并联块的支路要单独解一次电阻方程：RB + Ron/2 = Ron ⇒ RB = Ron/2，故 B 取 2(W/L)S，C、D 各取 (W/L)S
A + BC + BD5三条纯串联支路每条支路用（5.3）：BC 与 BD 两条支路里的每只管子都取 2(W/L)S（B 在两条支路里各占一只），A 取 (W/L)S

笔记的结论是"实际中更可能为 A + BC + BD"。理由在表里最后一列：纯串联支路的尺寸可以直接套（5.3）的"每管加倍"规则，而成 B(C+D) 那样夹着并联块的支路，必须先解一次电阻方程才能定尺寸；多一只管子换一套统一的尺寸规则，是这类设计里常见的取舍。

关键块：网络函数与输出函数差一个反

表里第三行容易被跳过，但它是复合门最容易错的地方：下拉网络实现的是 F 的串联-并联结构，而输出等于这个结构的反。所以按"串=与、并=或"摊出来的网络，直接量输出得到的是 F̄。要让输出真的等于 F，后面还要一级反相器（或者把输入的极性反过来取）。反相器的情形可以直接核对：网络只有一只管子，网络函数是 A，输出是 Ā——正是 NOT。

6 · 带 CL 的开关时间

前面五章都假设输出瞬间建立。实际输出节点上挂着下一级的栅极电容、连线电容，输出电压只能靠有限的电流给电容充放电。这一章把充放电过程解出来，得到三个数：tf、tr、tp。

6.1 RC 模型的通解

把输出节点看成一个电容 CL，把"驱动管 + 负载管"合起来看成一个电阻 R 接在 CL 与目标电平之间。放电时目标电平是 VL，充电时是 VH。以放电为例，令 u ≡ 𝒱O − VL（离目标还差多少），流出电容的电流就是 u/R：

(6.1) CL d𝒱Odt = −𝒱O − VLR ← 电容电流 = 流过 R 的电流（符号取流出） CL dudt = −uR ← 代入 u 的定义（VL 为常数，d𝒱O/dt = du/dt） duu = −dtR CL ← 两边同乘 dt/(CLu) ln u = −tR CL + A ← 两边积分（A 为积分常数） u = u(0) e−t/(RCL) ← 两边取指数，并把 eA 写成 u(0)

把 u 换回电压，并记摆幅 ΔV ≡ VH − VL、时间常数 τ ≡ R CL：

(6.2) u(0) = VH − VL = ΔV ← t = 0 时输出在 VH 𝒱O(t) = VL + ΔV e−t/τ ← （6.1）末行加回 VL、代入 ΔV

（6.2）的物理含义全在 e−t/τ 这一项里：它与初始差距 ΔV 成正比，所以电压不是匀速下降，而是越接近 VL 越慢。每过一个 τ，剩下的差距缩到原来的 e−1 = 36.8%。反过来，要把差距缩到某个比例，所需时间正比于 τ，比例只出现在对数的自变量里——这就是下面三组时间都写成"系数 × τ"的原因。

6.2 tf、tr 与 tp

三个时间点都由（6.2）反解。先求 90% 与 10% 两个时刻（从 VH 起算，差距为 ΔV）：

(6.3) 0.9 ΔV = ΔV e−t/τ ← （6.2）取 𝒱O = VL + 0.9ΔV 0.9 = e−t/τ ← 两边除 ΔV ln 0.9 = −t/τ ← 两边取自然对数 t90% = −τ ln 0.9 = 0.105τ ← 两边乘 −τ；ln 0.9 = −0.105
(6.4) 0.1 ΔV = ΔV e−t/τ ← （6.2）取 𝒱O = VL + 0.1ΔV 0.1 = e−t/τ ← 两边除 ΔV t10% = −τ ln 0.1 = 2.303τ ← 取对数、乘 −τ；ln 0.1 = −2.303

下降时间定义为这两个时刻之差：

(6.5) tf = t10% − t90% ← 10%–90% 的定义 = 2.303τ − 0.105τ ← 代入（6.4）、（6.3） = 2.198τ ← 合并同类项 ≈ 2.2 Ron,S CL ← 四舍五入；放电经 MS，故 τ = Ron,SCL

传输延迟取 50% 时刻（从输入跳变的中点起算）：

(6.6) 0.5 ΔV = ΔV e−t/τ ← （6.2）取 𝒱O = VL + 0.5ΔV ln 0.5 = −t/τ ← 两边除 ΔV、取对数 tpHL = −τ ln 0.5 = 0.693 Ron,S CL ← 乘 −τ；ln 0.5 = −0.693

充电方向完全同形：把 VL 换成 VH、把 Ron,S 换成 Ron,L，起始差距同样是 ΔV：

(6.7) 𝒱O(t) = VH − ΔV e−t/τL ← （6.2）把 VL ↔ VH 对调 tr = 2.2 Ron,L CL ← 同（6.5）的推导 tpLH = 0.693 Ron,L CL ← 同（6.6）的推导

（6.5）与（6.7）合起来说明一件事：上升与下降的时间之比，就是两只管子导通电阻之比。伪 NMOS 里 K′P 大约是 K′N 的 0.4 倍，上拉管的 Ron 因此是下拉管的 2.5 倍上下，tpLH 就是 tpHL 的 2.5 倍左右——这是伪 NMOS 最明显的短板。

6.3 等效电阻与数值示例

（6.5）（6.6）用的 Ron 是常数，而实际的 Ron 在整个过渡区间里会变（VDS 从 ΔV 一路降到 0，驱动管先饱和、后进三极管区）。课件把这个变化平均成一个等效电阻：

(6.8) Req = 1.7 Ron ← 课件拟合系数（对 10%–90% 区间取平均）

把（6.8）代进（6.5）（6.6）：

(6.9) tp = 2.2 Req CL ← （6.5）把 Ron 换成 Req = 2.2 (1.7 Ron) CL ← 代入（6.8） = 3.74 Ron CL ← 乘法；笔记取 3.7 tpHL = 0.693 (1.7 Ron,S) CL ← （6.6）同样代入 = 1.18 Ron,S CL ← 乘法；笔记取 1.2

（6.8）的系数 1.7 不带闭式来源，它是把实际波形平均出来的：用常数 Ron 与用等效 Req，同一个电路的两个延迟差 1.7 倍。

数值示例。 取 §4.3 的耗尽型负载反相器（(W/L)S = 1.80、(W/L)L = 1.60、K′N = 100 µA/V²、VTN,S = 0.6 V、VTN,L = −1 V），设 CL = 0.1 pF。先算两个 K 与两个 Ron：

(6.10) KS = ½K′N(W/L)S = ½(100×10−6)(1.80) = 90.0 µA/V² ← K 的定义 KL = ½K′N(W/L)L = ½(100×10−6)(1.60) = 80.0 µA/V² ← K 的定义 Ron,S = 12(90.0×10−6)(2.5 − 0.6) = 2.92 kΩ ← （1.6）式，VOV = 1.9 V Ron,L = 12(80.0×10−6)(0 − (−1)) = 6.25 kΩ ← （1.6）式，VOV,L = 1 V

再算时间：

(6.11) tpHL = 0.693 Ron,S CL ← （6.6）式 = 0.693 (2.92×103)(0.1×10−12) ← 代入数值（CL = 0.1 pF = 0.1×10−12 F） = 0.693 (2.92×10−10) ← Ω 与 F 相乘得 s = 2.02×10−10 s = 0.20 ns ← 乘法
(6.12) tpLH = 0.693 Ron,L CL ← （6.7）式 = 0.693 (6.25×103)(0.1×10−12) ← 代入数值 = 0.693 (6.25×10−10) ← 乘法 = 4.33×10−10 s = 0.43 ns ← 乘法

两个方向的延迟差 2.1 倍，原因就在（6.10）最后两行：Ron,L/Ron,S = 6.25/2.92 = 2.14。若改用等效电阻（6.9）的 1.18 与 1.7 两个系数，同样的电路给出 tpHL = 1.18(2.92×10−10) = 0.34 ns，比 0.20 ns 大 1.7 倍。
