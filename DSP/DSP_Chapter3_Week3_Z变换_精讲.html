01为什么需要 z 变换 · 定义与 z 平面slide 2–4 · §3.1

z 变换是连续时间拉普拉斯变换的离散对应物。引入它的动机很直接：傅里叶变换并非对所有序列都收敛，需要一种“带收敛因子”的推广。

动机

X(ejω) = ∞∑n=−∞x[n]e−jωn 要求这个级数收敛。像 2nu[n] 这种指数增长的序列，DTFT 根本不存在（级数发散）。z 变换的思路是：先乘一个指数衰减因子 r−n 把序列压住，再做傅里叶变换；只要 r 选得合适，收敛就能恢复。

定义（双边 z 变换）

z 变换　X(z) = ∞∑n = −∞x[n] z−n 对照 FT　X(ejω) = ∞∑n = −∞x[n] e−jωn

差别只有一个：e−jωn 的模恒为 1，而 z−n 的模 |z|−n 可以是任意正数 —— 这就是“可调收敛因子”的来源。

极坐标 z = r ejω：z 变换与 FT 的桥梁

X(rejω) = ∞∑n=−∞x[n] (rejω)−n = ∞∑n=−∞(x[n] r−n) e−jωn 即：X(rejω) 就是序列 x[n]r−n 的傅里叶变换

令 r = 1（即 |z| = 1，单位圆），就回到普通的 DTFT：

X(ejω) = X(z)|z = ejω
一句话记住三者关系：z 变换 ⊃ DTFT。DTFT 是 z 变换在单位圆上的取值；所以“DTFT 存在” ⟺ “ROC 包含单位圆”。这句话后面会反复用到。

02收敛域 ROC 与收敛条件slide 5–6

ROC（Region of Convergence）是 z 变换里最重要的概念：同一个代数式配上不同 ROC，就是不同的序列。

ROC 定义：使 ∞∑n=−∞|x[n]z−n| < ∞（绝对可和）成立的所有 z

收敛只取决于 |z|

把 z = rejω 代入绝对可和条件：

∞∑n=−∞|x[n] r−ne−jωn| = ∞∑n=−∞|x[n]| r−n < ∞
结论：条件里没有 ω，只有 r = |z|。所以：若某个 z1 属于 ROC，则所有满足 |z| = |z1| 的 z 都属于 ROC。ROC 必然是由同心圆界定的环带（或圆盘）。

课件强调的一点：z 变换比 FT 更能“容忍”增长的序列

序列 r−nu[n]（也就是 (1/r)nu[n]）当 r > 1 时是衰减的，绝对可和；而 u[n] 本身不绝对可和。乘上 r−n 这个“人为的收敛因子”后，原本发散的级数就可以收敛 —— 这正是 2nu[n] 有 z 变换（|z|>2）却没有 DTFT 的原因。

03两个基本例子：右边指数与左边指数slide 7–10 · 例 3.1 / 例 3.2

这两道题是整章的“母题”：它们的 X(z) 代数式完全一样，只有 ROC 不同，却对应完全不同（时间上反向）的两个序列。

例 3.1　x[n] = anu[n]（右边序列）

X(z) = ∞∑n = 0anz−n = ∞∑n = 0(a z−1)n 收敛要求 |a z−1| < 1 ⟺ |z| > |a| ⟹ X(z) = 11 − a z−1 = zz − a,   |z| > |a|

零点在 z = 0（z/(z−a) 形式的分子），极点在 z = a。ROC 是过最外极点之外的圆外区域，不含极点本身。

例 3.2　x[n] = −anu[−n−1]（左边序列）

X(z) = −−1∑n = −∞anz−n  （换元 m = −n）  = −∞∑m = 1(a−1z)m 收敛要求 |a−1z| < 1 ⟺ |z| < |a| ⟹ X(z) = 11 − a z−1,   |z| < |a|
核心对照（必须记住）：
序列判断变换ROC
anu[n]右边1/(1 − a z−1)|z| > |a|
−anu[−n−1]左边1/(1 − a z−1)|z| < |a|
代数式相同、ROC 相反 ⟹ 序列一个向右、一个向左。做题时“先看 ROC 再查表”，否则会把左边序列写成右边序列。

什么时候 DTFT 不存在？

例 3.1：|a| > 1 ⟹ ROC |z| > |a| > 1，不含单位圆 ⟹ DTFT 不存在 例 3.2：|a| < 1 ⟹ ROC |z| < |a| < 1，不含单位圆 ⟹ DTFT 不存在
判据：不必真的去算 DTFT。看 ROC 是否包含 |z|=1 就够了。这也是 Week 2 里“绝对可和 ⟺ DTFT 存在”的 z 域版本。

04三个进阶例子：和、双边、有限长slide 11–18 · 例 3.3 / 3.5 / 3.6

这三个例子把“ROC 由谁决定”讲透：和的 ROC 取交集、双边的 ROC 是环带、有限长序列的 ROC 几乎整个平面。

例 3.3　两个右边序列之和slide 11–13

x[n] = (12)nu[n] + (−13)nu[n]
X(z) = 11 − ½z−1 + 11 + ⅓z−1 = 2 − ⅙z−1(1 − ½z−1)(1 + ⅓z−1),   |z| > 12

两极点在 z = ½ 与 z = −⅓；分子 2 − ⅙z−1 = 0 给零点 z = 1/12。ROC 是两个单项 ROC（|z|>½ 与 |z|>⅓）的交集，即 |z|>½。

例 3.5　一个右边 + 一个左边 = 双边slide 14–15

x[n] = (13)nu[n] − (12)nu[−n−1]
(⅓)nu[n] ⟷ 11 − ⅓z−1,  |z| > 13     −(½)nu[−n−1] ⟷ 11 − ½z−1,  |z| < 12 ⟹ X(z) = 2 − ⅚z−1(1 − ⅓z−1)(1 − ½z−1),   13 < |z| < 12

ROC 是两个区间的交集，恰好形成一个环：⅓ < |z| < ½；零点在 z = 5/12。注意这个环不含单位圆 → 该序列的 DTFT 不存在。

例 3.6　有限长序列slide 16–17

x[n] = an,  0 ≤ n ≤ N−10,    otherwise
X(z) = N−1∑n = 0(az−1)n = 1 − aNz−N1 − a z−1 = 1zN−1 zN − aNz − a

零极点分布：分子的 N 个根是

zk = a ej(2πk/N),   k = 0, 1, …, N−1

其中 k = 0 的零点 z = a 恰好与分母的极点 a 相消；剩下的 zN−1 给出 z = 0 处一个 N−1 阶极点（课件取 N = 16、0 < a < 1，即“15th-order pole”）。

结论：有限长序列的 ROC 是除 z = 0 以外的整个 z 平面（0 < |z| < ∞）。因为求和只有 N 项，只要能算出来就收敛；唯一的问题是 z−n 在 z = 0 处发散。
看似有极点、其实没有： 1/(1 − az−1) 这个分母让 X(z) “看起来”在 z = a 有极点，但分子同时为零，极点被零点抵消，序列仍然是有限长的。“代数式里有分母” ≠ “有极点”，一定要检查零极点是否相消 —— 这一条在 Tutorial Q3(g) 和 Q5 里都会再用到。

05ROC 的八条性质slide 19 · §3.2

这八条是“不看图也能定 ROC”的全部依据，做题时逐条对照即可。

#条件ROC 的形状
1任意序列 以原点为中心的环带或圆盘：0 ≤ rR < |z| < rL ≤ ∞
2DTFT 绝对收敛 ROC 包含单位圆（|z| = 1）
3任意序列 ROC 不能含任何极点
4有限长序列 整个 z 平面，可能除去 z = 0 或 z = ∞
5右边序列 从最外有限极点向外扩张，可含 ∞
6左边序列 从最内非零极点向内收缩，可含 0
7双边序列 一个环带，内外边界都由极点界定（不含极点）
8任意序列 ROC 必须连通（不能是两段分离的区域）
第 8 条为什么重要：它把“可能的 ROC”限制在少数几种。例如有三个极点（半径 r1 < r2 < r3）时，合法的 ROC 只有四种：|z|<r1、r1<|z|<r2、r2<|z|<r3、|z|>r3 —— 不可能出现 r1<|z|<r3（它含掉 r2 处的极点，违反第 3 条）。

07稳定性、因果性与 ROCslide 22–23

系统性质完全由 ROC 决定。因果看 ROC 是否在最外极点之外；稳定看 ROC 是否包含单位圆。

设 H(z) 的极点在 z = ½ 与 z = 2，则只有三种可能的 ROC，对应三个不同的系统：

若要求稳定：ROC 必须含单位圆 ⟹ 取 ½ < |z| < 2 ⟹ 该 ROC 是环带 ⟹ h[n] 双边 ⟹ 非因果 若要求因果：ROC 必须在最外极点之外 ⟹ 取 |z| > 2 ⟹ 不含单位圆 ⟹ 不稳定
结论：对这对极点，“既稳定又因果”是不可能的。原因：稳定要求 ROC 是个“跨过单位圆”的圆环，而因果要求 ROC 是个“向外延伸到 ∞”的圆外区域 —— 当一个极点在单位圆外（|z|=2>1）时，这两个要求无法同时满足。
两条通用判据（后面 Tutorial Q1/Q5 反复用）：
  • 因果 ⟺ ROC 是某个圆的外部（|z| > rmax，可达 ∞）⟺ 最外极点之外。若 ROC 是环带或圆盘，则非因果。
  • 稳定 ⟺ ROC 包含 |z| = 1。对有理 H(z)，等价于所有极点都在单位圆内（此时 ROC 取最外极点之外时天然含单位圆）。
所以对因果系统：稳定 ⟺ 全部极点满足 |pk| < 1。这句话是 Chapter 3 最实用的一条结论。

08逆 z 变换（一）：部分分式展开，M < Nslide 24–27 · §3.3

课件直接进入最实用的方法：把有理分式拆成若干 1/(1−dkz−1) 之和，再逐项查表。前提是分子阶数低于分母（M < N），且极点都是一阶的。

一般形式与零极点计数

X(z) = M∑k = 0bkz−kN∑k = 0akz−k = b0a0 M∏k = 1(1 − ckz−1)N∏k = 1(1 − dkz−1)
零极点个数

M 个零点、N 个极点位于非零位置（即 ck, dk）。

z = 0 处还有几个

M < N：z = 0 处有 N − M 个零点；
M > N：z = 0 处有 M − N 个极点。

总数相等

有限零点总数 = 有限极点总数（都等于 max(M,N)）。所以不存在“无穷远处的零点或极点”这种说法。

展开公式（M < N，一阶极点）

X(z) = N∑k = 1Ak1 − dkz−1 Ak = (1 − dkz−1) X(z)|z = dk

求 Ak 的口诀：把该极点对应的因子“盖住”，再把 z = dk 代进剩下的式子。

例：二阶 z 变换slide 26–27

X(z) = 1(1 − ¼z−1)(1 − ½z−1),   |z| > 12
A1 = (1 − ¼z−1)X(z)|z = ¼ = 11 − ½·4 = −1 A2 = (1 − ½z−1)X(z)|z = ½ = 11 − ¼·2 = 2

（注意 z = ¼ ⟺ z−1 = 4，代入的是 z−1 而不是 z。）

X(z) = −11 − ¼z−1 + 21 − ½z−1 ⟹ x[n] = 2(12)nu[n] − (14)nu[n]
为什么两项都是 u[n]：因为 ROC 是 |z| > ½，两个极点都被包在 ROC 内部，所以每一项按“右边序列”查表（1/(1−az−1) ↔ anu[n]）。ROC 决定方向，部分分式只决定系数 —— 这是本节最容易错的地方。

09逆 z 变换（二）：M ≥ N 与重极点slide 28–31

分子阶数不低于分母时，先做长除法分离出多项式部分（对应 δ[n] 及其移位），剩下的真分式再做部分分式。

X(z) = M−N∑r = 0Br z−r + N∑k = 1Ak1 − dkz−1 除法在余式次数低于分母时停止；多项式部分的每一项 Brz−r 就是一个 Brδ[n−r]

X(z) = M−N∑r=0Brz−r + N∑k=1Ak1 − dkz−1 + s∑m = 1Cm(1 − diz−1)m Cm = 1(s − m)! (−di)s−m {ds−mdws−m[(1 − diw)s X(w−1)]}|w = 1/di
实际做题的做法：重极点项很少真用这个公式，通常用通分比较系数更快。公式的价值在于告诉你“重极点会产生 (1−diz−1)−m 各次幂”，而 m ≥ 2 的项查表得到的是带 n 因子的项：1/(1−az−1)2 ↔ (n+1)anu[n]（Tutorial Q2 就用这条）。

X(z) = 1 + 2z−1 + z−21 − 32z−1 + 12z−2 = (1 + z−1)2(1 − ½z−1)(1 − z−1),   |z| > 1

第 1 步　长除法（M = N，只需除一次）：

X(z) = 2 + −1 + 5z−1(1 − ½z−1)(1 − z−1)

（验证：2(1 − 1.5z−1 + 0.5z−2) + (−1 + 5z−1) = 2 − 3z−1 + z−2 − 1 + 5z−1 = 1 + 2z−1 + z−2 ✓）

检算：x[0] = 2 − 9 + 8 = 1，而 X(z) 在 z−1→0 时的极限是 1/1 = 1 ✓ （这个“z−1→0 极限 = x[0]”是所有右边序列都成立的快速检查。）

10逆 z 变换（三）：幂级数展开（只有 z = 0 极点时）slide 32–33

当 X(z) 是有限项多项式时，部分分式根本用不上（没有非零极点可拆），直接把系数读出来即可。

X(z) = z2(1 − ½z−1)(1 + z−1)(1 − z−1)
课件的判断：“Its only poles are at z = 0, so the partial fraction expansion is inappropriate!” —— 唯一的极点在 z = 0（而且是以 z−2 的形式出现），拆不出 1/(1−dkz−1) 这种项，所以改用幂级数。

第 1 步　乘开：

X(z) = z2 − ½z − 1 + ½z−1

第 2 步　与定义式逐项对照（z 的正幂对应负的 n）：

X(z) = ∞∑n=−∞x[n]z−n = ⋯ + x[−2]z2 + x[−1]z + x[0] + x[1]z−1 + ⋯
x[−2] = 1,  x[−1] = −½,  x[0] = −1,  x[1] = ½,  其余为 0
答案：x[n] = δ[n+2] − ½δ[n+1] − δ[n] + ½δ[n−1]，ROC：整个 z 平面（除 z=0）。
这一节的核心陷阱：不要把所有东西都化成 z−1 的形式。一旦把 z2 改写成 z−(−2) 之外的形式（例如整体除以 z2），n 的索引就全乱了。安全做法：保留正幂，逐项读 n = −(指数)。

第 1 条的补充：零极点相消会让 ROC 变大slide 35

课件给的例子正是第 4 节那个有限长序列：

x[n] = anu[n] − anu[n−N]

两项都是右边序列、都在 z = a 有极点，各自的 ROC 都是 |z| > |a|。但相加之后：

z = a 处的极点被 z = a 处的零点抵消 ⟹ ROC 变成除 z = 0 以外的整个 z 平面（比交集 |z|>|a| 大得多）
结论：“ROC 等于交集”只在没有零极点相消时成立。一旦相消，ROC 可以扩张。这一点在 Tutorial Q5 里是解题的关键（H(z)X(z)=Y(z) 的 ROC 比 RH ∩ RX 大）。
第 2 条要小心的地方：时移会改变 z=0 与 z=∞ 处的零极点个数。例如 x[n] = δ[n] 的 ROC 是整个平面，但 x[n−1] = δ[n−1] 的变换是 z−1，在 z = 0 处有极点，ROC 变成 0 < |z| < ∞。“ROC 只在 z=0 或 ∞ 处可能变”这句话就是这个意思。

Q1

H(z) = 1 − 4z−1(1 − z−1)(1 − 3z−1)

(i) zeros & poles　(ii) all ROCs and the inverse transform for each　(iii) causality & stability per ROC
i求零点与极点

零点：分子为零

1 − 4z−1 = 0  ⟹  z = 4

极点：分母为零

(1 − z−1)(1 − 3z−1) = 0  ⟹  z = 1,  z = 3
答案：零点 z = 4；极点 z = 1, 3。
教学点1 − az−1 = 0 ⟺ z = a。所以“1 − 4z−1”给零点 z = 4，“1 − 3z−1”给极点 z = 3 —— 分子给零点、分母给极点，位置就是常数项本身（不是它的倒数）。
ii部分分式展开与三种 ROC 下的 h[n]

第 1 步　设部分分式（两个一阶极点，且 M = N = 1… 展开后分子阶数降为 0，直接用 A/(1−dkz−1) 形式）：

H(z) = A1 − z−1 + B1 − 3z−1

第 2 步　通分比较系数：

1 − 4z−1 = A(1 − 3z−1) + B(1 − z−1) = (A + B) + (−3A − B)z−1 A + B = 1   …①     −3A − B = −4   …②

由 ① 得 B = 1 − A，代入 ②：

−3A − (1 − A) = −4  ⟹  −2A = −3  ⟹  A = 32,   B = −12
⟹ H(z) = 3/21 − z−1 − 1/21 − 3z−1

验算：(3/2)(1−3z−1) − (1/2)(1−z−1) = 3/2 − 9/2 z−1 − 1/2 + 1/2 z−1 = 1 − 4z−1 ✓

第 3 步　列全部 ROC。两个极点半径是 1 和 3，所以候选 ROC 有 3 个：

|z| > 3   ⟷   1 < |z| < 3   ⟷   |z| < 1

ROC 1：|z| > 3　ROC 在最外极点之外 ⟹ 两项都按右边查表（1/(1−az−1) ↔ anu[n]）：

h[n] = 32u[n] − 123nu[n] = (32 − 123n)u[n]

ROC 2：1 < |z| < 3　环带把 z=1 包在内、把 z=3 挡在外 ⟹ 第一项右边、第二项左边（1/(1−az−1) ↔ −anu[−n−1] 当 |z|<|a|）：

h[n] = 32u[n] + 123nu[−n−1]

ROC 3：|z| < 1　ROC 在最内极点之内 ⟹ 两项都按左边查表：

h[n] = −32u[−n−1] + 123nu[−n−1] = (−32 + 123n)u[−n−1]
教学点注意 ROC 3 里第一项前面的负号变了：原本是 +3/2，左边配对后变成 −3/2（因为左边序列的标准对本身带一个负号）。“ROC 决定方向，方向决定符号”。
iii逐个 ROC 判断因果性与稳定性
ROCh[n]因果性稳定性
|z| > 3 (3/2 − ½·3n)u[n] 因果 不稳定
1 < |z| < 3 (3/2)u[n] + ½·3nu[−n−1] 非因果 不稳定
|z| < 1 (−3/2 + ½·3n)u[−n−1] 反因果 不稳定

判据：因果 ⟺ ROC 在最外极点之外（|z|>3）；稳定 ⟺ ROC 含单位圆 |z|=1。

结论：三种 ROC 全都不稳定。原因很干脆：极点 z = 1 正好落在单位圆上，而 ROC 不能含极点，所以任何 ROC 都不可能把整条单位圆包含进去 ⟹ 该系统无论取哪个 ROC 都不稳定。极点落在单位圆上 ⟹ 系统必不稳定，这是个可以一眼看出来的结论。
教学点（三个 ROC 的“身份”）
· |z|>3：右边序列 → 因果（实时可实现），但 3n 增长 ⟹ 不稳定。
· 1<|z|<3：双边 → 非因果；且单位圆不在环内（边界）⟹ 不稳定。
· |z|<1：全左边 → 反因果（必须知道全部未来）⟹ 不稳定。
做题时若题目只给 H(z) 而不给 ROC，要主动写出这三种情形并分别讨论 —— 这正是本题 (ii)(iii) 的考点。
Q2

求零状态响应：h[n] = (½)nu[n]，x[n] = (n+1)(¼)nu[n]

Compute the zero-state response (i.e. y = x ∗ h) using the z-transform
零状态响应就是“初始条件为零”时的输出，即 y[n] = x[n] ∗ h[n]。用 z 变换：Y(z) = H(z)X(z)，避免了硬算卷积。

第 1 步　求 H(z)（标准对 anu[n] ↔ 1/(1−az−1)，a = ½）：

H(z) = 11 − ½z−1,   |z| > 12

第 2 步　求 X(z)（用 (n+1)anu[n] ↔ 1/(1−az−1)2，a = ¼）：

X(z) = 1(1 − ¼z−1)2,   |z| > 14

第 3 步　相乘（ROC 取交集，|z| > ½）：

Y(z) = H(z)X(z) = 1(1 − ½z−1)(1 − ¼z−1)2,   |z| > 12

第 4 步　部分分式（一个一阶极点 + 一个二阶极点）：

Y(z) = A1 − ½z−1 + B1 − ¼z−1 + C(1 − ¼z−1)2
A = (1 − ½z−1)Y(z)|z−1=2 = 1(1 − ½)2 = 4 C = (1 − ¼z−1)2Y(z)|z−1=4 = 11 − ½·4 = −1 B：令 z−1 = 0，Y(0) = 1 = A + B + C = 4 + B − 1 ⟹ B = −2

第 5 步　逐项逆变换（1/(1−az−1)2 ↔ (n+1)anu[n]）：

y[n] = 4(½)nu[n] − 2(¼)nu[n] − (n+1)(¼)nu[n] = 4(½)nu[n] − (n + 3)(¼)nu[n]
答案：y[n] = [4(½)n − (n+3)(¼)n]u[n]
教学点
① 重极点项的系数不能用“盖住极点”的老办法直接求 B（会算出 0/0 之类），要么像上面这样用 z−1=0 的取值定出最后一个系数，要么用通分比较系数。求 A 和 C（对应最高阶与一阶项）可以直接盖住，B 要靠额外一个方程。
② 快速检算：y[0] = x[0]h[0] = 1·1 = 1；而答案给出 4 − 3 = 1 ✓。任何卷积结果都满足 y[0] = x[0]h[0]，这是最省时间的验算。

教学点把三条串起来：因果 ⟺ ROC 向外 ⟹ 稳定 ⟺ 最外极点在单位圆内。所以对因果有理系统，只看极点的模就够了，不必每次画图。反过来，若某个极点在单位圆外（如 Q1 的 z=3），因果系统一定不稳定。

第 4、5 行是全部题的枢纽：同一个 1/(1−az−1)，ROC 在外 → anu[n]（右边）；ROC 在内 → −anu[−n−1]（左边）。答题时必须先看 ROC 再查表。

二、三条判据（本节最重要）

x[n] 是右边序列（因果）　⟺　ROC 是最外极点之外的圆外区域（|z| > rmax，可含 ∞） 系统稳定（BIBO）　⟺　ROC 包含单位圆 |z| = 1　⟺　DTFT 存在 因果有理系统稳定　⟺　全部极点满足 |pk| < 1

三、ROC 的八条性质

形状与边界

以原点为中心的环带/圆盘；不含极点（但极点可以在边界上）；必须连通。

看支撑集

右边 → 向外；左边 → 向内；双边 → 夹在两极点之间；有限长 → 全平面（除 z=0/∞）。

数候选个数

有 k 个不同半径的极点 ⟹ k+1 个候选 ROC（k−1 个环 + 最内圆盘 + 最外圆外）。

四、逆 z 变换：三条路

情形方法要点
M < N，一阶极点 部分分式：X = Σ Ak/(1 − dkz−1)，Ak = (1 − dkz−1)X(z)|z=dk “盖住极点、代入求值”→ 逐项按 ROC 定左右
M ≥ N 先长除分出多项式（Σ Brz−r → ΣBrδ[n−r]），再对余式做部分分式 除法到余式次数 < 分母次数为止
重极点 多出 Cm/(1−diz−1)m 项；m ≥ 2 项查表得带 n 因子的序列 最高阶项与一阶项可“盖住”求，其余靠通分或代值
只有 z = 0 极点 / 有限多项式 幂级数：乘开，按 Σx[n]z−n 逐项读系数 正幂 ↔ 负 n；圆内 ROC 时按 z 正幂展开

五、五个好用的检算

① X(z)|z→∞（即 z−1→0） = x[0]　（右边序列） ② X(z)|z=1 = ∞∑nx[n]　（若 z=1 在 ROC 内） ③ 卷积结果满足 y[0] = x[0]h[0] ④ H(z)X(z) 的 ROC 若因相消而变大，检查分母是否被分子约掉 ⑤ 极点位置与 ROC 的半径边界必须一一对应（极点不能落在 ROC 内部）

六、易错点清单

只写 X(z) 不写 ROC同一代数式 + 不同 ROC = 不同序列。任何答案都要带 ROC，否则不完整。
把“有分母”当成“有极点”先约分！(1−½z−1)/(1−¼z−2) 其实没有 z=½ 的极点。
u[−n] 与 u[−n−1] 差一项前者含 n=0，变换从 1/(1−az−1) 变成 1/(1−2z) 之类，不能照抄标准对。
左边序列漏负号1/(1−az−1) 配 |z|<|a| 时是 −anu[−n−1]，前面有负号。
重极点求系数用“盖住法”最高阶项与一阶项可以直接盖，中间项盖住会得到 0/0，需通分或另取代值。
幂级数方向搞反ROC 是圆外 → 按 z−1 展开；圆内 → 按 z 的正幂展开。展错方向会得到发散的假结果。
正幂项对应负 nz2 项是 x[−2]，不是 x[2]。有限长例子最容易错。
极点在单位圆上若极点 |p|=1，任何 ROC 都不含整条单位圆 ⟹ 系统必不稳定（Tutorial Q1 就是这种）。
RY 可能大于交集零极点相消会让 ROC 扩大（Q5 的 RY 从 (⅔,2) 扩到 (⅔,∞)）。
a = 1 要单独讨论几何级数公式在 a=1 时分母为零，必须另算（Q6 的特例）。
